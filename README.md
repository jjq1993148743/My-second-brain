# IdeaVault · 我的想法库

一个把手机、电脑、任何地方冒出来的想法收拢起来，交给 AI 整理的库。

---

## 一、六个文件夹（只按"状态"分）

```
IdeaVault/
├── 00-收件箱/     所有想法先扔这里，不分类、不打标签、不思考
├── 10-想法池/     整理过、但还没决定要不要做
├── 20-已决定/     我决定要做的
├── 30-在做/       正在推进的
├── 40-产出/       AI 生成的东西（摘要、周报、聚类）——只有 AI 写
└── 90-归档/       做完了的、放弃了的
```

**你只需要关心 `00-收件箱`。** 其余五个由 AI 整理时移动，你只在"10-想法池 → 20-已决定"这一步做确认。

---

## 二、其余维度全用标签，不建文件夹

文件夹只能把一个东西放在一个地方，但一个想法往往同时属于多个维度。
所以除了"状态"，其他维度一律用标签：

| 维度 | 标签 | 说明 |
|---|---|---|
| 主题 | `#工作` `#创业` `#小点子` `#生活` `#学习` | 想加就加，不用提前设计 |
| 性质 | `#重点` `#灵感` `#问题` `#待验证` | `#重点` = 我反复想到的东西 |
| 时间 | 不用标签 | 文件里有 `date`，按日期排就是 |

**举个例**：一条"工作中的、我已经决定要做的、反复想过三次的想法"，它待在 `20-已决定/`，
标签是 `#工作 #重点`。三个维度同时表达，互不冲突。

## 三、一条想法长什么样

```markdown
---
date: 2026-09-25
time: 14:32
place: 办公室
tags: [工作, 重点]
---

想法正文，想到什么写什么。

## 下一步
（可选，一行就够）
```

只有两个字段必须填：**日期**和**正文**。其余 AI 整理时帮你补。

## 四、记录要快，整理要慢

| 环节 | 频率 | 谁做 | 要求 |
|---|---|---|---|
| 记录 | 随时，5 秒内完成 | 我 | 不分类、不打标签、写不完整都行 |
| 整理 | **每天一次** | AI | 拆分、补标签、放进对应文件夹 |
| 回顾 | 每周 15 分钟 | 我 | 清空收件箱，确认哪些进 `20-已决定` |

**为什么整理不是每小时一次：** 你一天可能就 3–5 条想法，每小时跑一次大部分时候是空转；
而且 AI 自动分类需要你的确认，跑太勤只会制造需要你处理的噪音。
真正要快的是"记录"，不是"整理"。

## 五、多端采集：5 秒内完成

| 场景 | 怎么做 | 落到哪 |
|---|---|---|
| 手机（iPhone） | 锁屏小组件 / 敲击背面 / 分享菜单 → 快捷指令，一句话语音 | `00-收件箱/今天.md` |
| 手机（懒得开 App） | 发给微信「文件传输助手」，晚上批量搬 | `00-收件箱/` |
| 电脑 | Obsidian 里 `Ctrl+N`，或直接编辑当天的文件 | `00-收件箱/` |

**判断标准：从"想到"到"写下来"不超过 5 秒。** 超过 5 秒，你最终就不会记。

## 六、让 AI 干活（三句话）

电脑上装 Claude Code，进到这个目录，直接说：

**每天**（可设成定时任务）
```
读 00-收件箱 里今天的文件，把想法拆分、补上标签，
移到 10-想法池，生成 3 行摘要写到 40-产出。
```

**每周**
```
读一周的 10-想法池，找出重复的观点、前后矛盾的地方，
把反复出现的标上 #重点，把可以合并的合并。
```

**随时**
```
我关于 [某个主题] 都想过什么？按时间顺序给我，并指出我观点变化的地方。
```

## 七、检索：先全文，后向量

| 层级 | 工具 | 解决什么 |
|---|---|---|
| 全文 | Obsidian 内置搜索 / Omnisearch 插件 | 记得关键词 |
| 语义 | Smart Connections 插件（本地向量，免费） | 记得意思但忘了词 |
| 问答 | 直接把库丢给 AI | "我关于 X 都想过什么" |

**别一上来就上向量库。** 几千条以内，全文搜索 + 好标签已经够快。

## 八、GitHub 的角色

GitHub **不做主同步**，只做版本历史与灾备：

- 主同步：Obsidian Sync（官方，付费最省心）或 Remotely Save 插件（免费，走坚果云 WebDAV）
- 版本层：桌面端装 `obsidian-git` 插件，每天自动 commit + push 到**私有仓库**

原因：手机端跑 Git 容易冲突。让 Git 在电脑上单向备份，既拿到版本历史，又不会打架。

## 九、配套的四个文件

| 文件 | 作用 |
|---|---|
| `总览.md` | **打开这个看全部。** 装 Dataview 插件后自动列出所有内容，永远最新。 |
| `总览.html` | 双击就能用浏览器打开的静态总览页，不需要装任何东西。不会自动更新。 |
| `_CLAUDE.md` | 给 AI 看的操作手册：目录约定、写笔记的规则、允许和禁止的操作。 |
| `USER.md` | 关于我：偏好、思维习惯、禁忌。**这份文件决定 AI 有多懂我。** 目前是模板，需要填。 |
