# photo-poster · 真实照片排版出图

做小红书/抖音竖图（1242×1656，3:4）。**核心是一条纪律：拟真画面用真实照片，不用文生图。**

## 先回答一个问题：这张图要「真」还是「好看」

| 需求 | 走哪条 | 说明 |
|---|---|---|
| 要拟真（真实猫、真实场景） | **真照片 + 排版** | 本技能主线。像素全是真的，无 AI 指纹 |
| 要信息清楚（清单、对比、流程） | **HTML 模板 + Chrome 截图** | 排版自由，同样无 AI 指纹 |
| 要「动作」或「不存在的画面」 | **停在告知** | 必须 AI 重绘，属 AI 生成内容，让用户决定 |

## 路线 A：真照片 + Pillow 排版（拟真优先）

### 素材要求

1. **一张主体照片**（前景清晰、有留白可压字）
2. **可选：参考图**（补充说明用的第二张，比如「吐出来的样子」）
3. **素材版权**：自己拍的 / 公有领域 / CC 授权，并在图上标来源

### 版式 1：全幅照片 + 底部渐变压字（封面首选）

```python
# 关键步骤（完整脚本见 scripts/make_cover.py）
1. 按 3:4 裁切，主体偏中上
2. 上淡下浓的垂直渐变遮罩（从 42% 高度开始渐入）
3. 压字：主标 100px / 副标 46px / 要点 33px，全部白色或亮色
4. 左上角 pill 标签（栏目名）
5. 底部版权/来源行 22px 灰白
```

### 版式 2：照片 + 奶油色信息板（内页/清单）

```
上 2/3 放照片，下 1/3 奶油色信息板（#FFF4E5）
信息板顶部一条 8px 橘色分隔线
标题 66px 深棕，要点 33px，编号用① ② ③ ④
```

### 版式 3：实拍参考（白框内嵌）

**不要试图把参考图融进主图** —— 融不进去就会「假」。正确做法是明确框出来：

```
白框 + 圆角 16px + 下方小字说明「实拍：xxx」
尺寸约 250×188，放右下角，避开主体
```

## 路线 B：HTML 模板 + Chrome 截图（排版优先）

1. 写 HTML（固定 body 宽高 = 1242×1656）
2. Chrome headless 截图：

```bash
chrome --headless --disable-gpu \
  --screenshot="out.png" --window-size=1242,1656 --hide-scrollbars \
  "file:///path/to/template.html"
```

3. 模板要点：`* { margin:0; padding:0; box-sizing:border-box }`，字体用 `"PingFang SC","Microsoft YaHei"`

## 验收清单（每次出图必查）

| # | 检查项 |
|---|---|
| 1 | 尺寸精确 1242×1656 |
| 2 | 文字无溢出、无截断 |
| 3 | 主体未被文字遮挡（眼睛、脸） |
| 4 | 有来源标注（数据出处 + 图片来源 + 授权） |
| 5 | 照片不是文生图（如果是，必须标注） |

## 什么时候必须停手并告知用户

出现以下需求时，**不要硬做**，要明确说清：

| 需求 | 为什么停 |
|---|---|
| 「把这只猫 P 成正在吐」 | 改动作只能 AI 重绘，传统 PS 拼素材会「假」 |
| 「合成一张不存在的场景」 | 同上 |
| 「抹掉 AI 水印/元数据」 | 涉及规避标注，不做 |

**标准话术：**
> 这个需求需要改变主体形态，传统 PS 拼素材做不到自然效果（我们试过 4 版，都会「假」）。要么用你实拍的照片，要么用 AI 重绘——但后者属于 AI 生成内容，平台要求标注，具体怎么处理你决定。

## 已知的失败路径（别再试）

这些是我实际试过并且失败的，记录下来避免重复浪费时间：

| 尝试 | 结果 | 原因 |
|---|---|---|
| 抠图 + 羽化 + 投影贴到另一张照片 | 假 | 光照方向、机位、分辨率都不同 |
| 颜色分割自动抠图 | 失败 | 主体与背景同色（米色呕吐物 vs 米色瓷砖） |
| 颜色去污 + 亮度统计匹配 + 景深匹配 | 假（变模糊） | 修掉了光晕但丢了细节 |
| 期望 Wikimedia 有「猫正在吐」的动作照 | 无 | 搜 10 组关键词，只有吐完的现场 |

**结论：跨照片合成元素，除非光照机位完全一致，否则一定假。不要在这上面反复迭代。**
