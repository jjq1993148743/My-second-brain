# 实例记录

## 01-猫呕吐科普（2026-10-22）

| 项 | 内容 |
|---|---|
| 主体照片 | Wikimedia Sick cream-colored kitten.jpg（CC BY 2.0） |
| 参考图 | Wikimedia Cat vomit.jpg（公有领域） |
| 风格 | A（渐变封面，带白框参考图）+ B（信息板） |
| 尺寸 | 1242x1656 |
| 产物 | 真照片封面A-病猫+实拍参考.jpg / 真照片封面B-病猫+信息板.jpg |

### 命令行复现

    python make_cover.py ^
      --photo 病猫.jpg --inset 呕吐物.jpg ^
      --style A --label "猫咪健康 · 自查" ^
      --title "猫吐了？ / 先别慌" --sub "这 4 种情况 · 对号入座" ^
      --points "① 饭后吐粮粒  ② 清晨吐黄水|③ 伸脖咔咔  ④ 带血丝" ^
      --source "数据来源：猫病学第5版 · 照片 Wikimedia" ^
      --out 封面A.jpg

（title 里用 / 表示换行，脚本会把 / 转成换行）

### 关键参数

| 参数 | 值 | 说明 |
|---|---|---|
| 渐变起点 | 42% 高度 | 再低会压到主体 |
| 主标字号 | 104px | 两行标题 |
| 裁切偏移 | 0.5 横 / 0.35 纵 | 人脸落在上三分线 |
| 内嵌图尺寸 | 250x188 | 再大会抢主体 |
