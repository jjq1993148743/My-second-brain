What is DeepSeek Harness (DSH)?

DeepSeek Harness (DSH) is DeepSeek AI's open-source agent framework, built on "everything is a plugin": models, tools, skills and interfaces are all composed of DSH plugins, freely replaceable and recombined. The official team builds the core; the community builds the ecosystem.

「Every part of the product is a plugin — including the model adapter, the tool registry, the session log, and the agent loop itself.」

— DeepSeek Harness architecture docs
Sources:Official siteArchitecture docsRepository
Agent framework

An agent harness orchestrating models, tools and interfaces — not a model or a chat tool

Everything is a plugin

Models, tools, interfaces and skills plug in and extend on demand

Powered by Cordis

A lightweight plugin runtime; plugins export apply(ctx) to register capabilities

Developer preview

Fast-moving with breaking changes; compatibility status must be labeled

Download and install your first DSH plugin in three steps

From launching DeepSeek Harness to installing your first community plugin, it takes just three commands — get up and running with DSH plugins in under a minute.

Source: DeepSeek Harness official QuickStart
Step 1
Launch DSH

Start DeepSeek Harness with one command; the Web UI opens at 127.0.0.1:3080.

npx @deepseek-ai/dsh web
Step 2
Install a plugin

Install a community plugin by forwarding pnpm via dsh plugin in the web profile directory; the framework loads and registers it automatically.

dsh plugin --profile web add <package>

Discover plugins

Frequently asked questions about DSH plugins and DeepSeek Harness plugins, answered directly.

All community DSH plugins live right here on dsh-plugin.org, the community hub for DeepSeek Harness (DSH). The entry points are simple: the search box at the top of the homepage for instant search, the "Plugins" link in the top navigation for the full list, and eleven category shortcuts on the homepage that open each category's landing page. Search by name or browse by category — it all happens in one place.
This hub organizes DSH plugins into eleven primary categories for easy browsing and filtering: UI & Experience (themes, sidebars, panels), Sessions & Messages (prompts, input, session management), Memory & Context (compaction, recall, persistence), Tools & Capabilities (search, files, shell), Skills & Agents (skills, subagents), Workflow & Automation (orchestration, approval), Integrations & Connections (MCP, notifications, bridges), Models & Reasoning (third-party models, routing), Development & Operations (debugging, testing, diagnostics), Data & Knowledge (visualization, knowledge bases), and Entertainment (games, pets). Type a plugin name, capability or tag into the search box on the homepage. In the plugin hub you can browse by eleven primary categories and filter by compatibility status (verified / unconfirmed) and DSH target version (dshTarget) to quickly find what you need.
Start DeepSeek Harness with npx @deepseek-ai/dsh web (Web UI at http://127.0.0.1:3080), then download and install a plugin with the official CLI: dsh plugin --profile web add <package>. It forwards pnpm inside the web profile directory, and DSH auto-loads and registers the plugin on startup.
The community DSH plugins listed here are open-source and free — browse, search, download and install by category at no cost. DeepSeek Harness itself is also an open-source project by DeepSeek AI.
This hub has hand-curated 10000+ DSH plugins, each reviewed by our professional technical team, expanded through user submissions and proactive market screening, and updated daily — new plugins are listed promptly and existing entries refreshed regularly, with the last-updated time shown on each page.
Check three fields: compatibility status (verified / unconfirmed), DSH target version (dshTarget), and repo activity (stars and last update). This hub labels every DSH plugin with these by hand; anything unverified is marked unconfirmed.
Every DSH plugin links back to its GitHub repository with stars, forks and last-updated time. This site's content is drawn from the DeepSeek Harness official site, architecture docs and repository, so everything you see is traceable.
DSH is in developer preview, and the official docs warn of breaking changes, so DSH plugins declare a dshTarget (e.g. rc.6) for the version they target. This hub displays that field; if a plugin breaks after an upgrade, its maintainer needs to update it.

Why does this DSH plugin community exist?

The official team builds the DSH core and the Cordis runtime, doesn't accept external PRs, and doesn't run a plugin registry. Community plugins just sit scattered across GitHub under the dsh-plugin topic, with no one collecting or verifying them. So we built this site.

Source: DeepSeek Harness official site
Official DeepSeek AI

The official team builds the DSH core and the Cordis runtime that powers "everything is a plugin." It doesn't accept external PRs, keeping its focus on the core, and asks community plugins to tag themselves dsh-plugin so they're easy to find.

Community dsh-plugin.org

We collect plugins tagged dsh-plugin, sort them into eleven primary categories, and label their compatibility and verification status. This fills the registry layer the official team hasn't built yet — linking back without ever pretending to be official.

To be clear, this is a community project with no affiliation with DeepSeek AI. The plugins listed here all work with the official DeepSeek Harness (DSH), and we simply organize them while linking back to the official repository and docs.
