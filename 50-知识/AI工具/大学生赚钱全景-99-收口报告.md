# 大学生赚钱全景 · 99 · 收口报告（三线汇总 + 可执行建议）

> **这是「大学生人群深研」的最终收口。**
> **三份分报告：00 我亲自验真 / 01 国外篇 / 02 国内篇 / 03 验证篇。**
> **这份报告只做一件事：把所有发现压成「能不能干、怎么干」。**

## 一、⭐⭐ 一句话结论

> **「大学生搞钱」这门生意是真的，但「月入过万」的传说基本是假的。真实分布是：极少数人赚到月 2-4 万然后退出，大多数人一个月几十到几百。能赚到钱的人一致说：流量得花钱买、客户资源比技术重要、这行不是长久之计。**

## 二、⭐⭐ 三个最硬的发现（都有原始信源）

### 发现 1：唯一一份真实账本，天花板是月 2-4 万，而且他已经半退出

| 项 | 内容 |
|---|---|
| 出处 | V2EX t/1233430《分享一下这 4 年来的接单记录》（2026-08-11，本人自述） |
| 客户 | 「客户群体基本没变，就是学生群体」 |
| 收入轨迹 | 2022年3单600元 → 2023年底月1万 → 2024年3-5月月2万 → 2024年底-2025年中**月2-4万** |
| 单笔价格 | 毕设单 2k-3k |
| **本人的话** | **「学生单性价比不高」「接单始终不是长久之计」「客户资源永远比技术重要」** |
| **退出原因** | **「闲鱼自然流量已经不行了，必须得充钱才能维持流量，一天50的预算能来10个人」** |

**这是全研究里唯一一份逐年逐月报数的账本。它的价值：给了这条路真实的天花板，也给了退出的真实原因。**

### 发现 2：付费意愿的真相——付钱的是家长/公司，不是学生本人

| 市场 | 价格 | 谁付钱 |
|---|---|---|
| 美国 ACT 一对一 | **$200-300/小时** | **家长** |
| 美国升学顾问 | **$200/小时**（顶级 $12万/年） | **家长** |
| 美国简历审阅 | **$400/次** | 求职者/家长 |
| **线上家教（学生市场）** | **$15-30/小时** | **学生本人** |
| 国内牛客课程 | ¥99（销量第1，68165人） | 学生本人 |
| 国内牛客课程 | ¥599（算法班仅244人） | 学生本人 |

**同样是辅导，家长市场和学生市场差 10 倍。** 而美国学生自己在校内打工就有 $15/小时，所以 $15 的线上家教对美国人毫无吸引力。

**推论：想赚学生的钱，要么做极低价走量，要么绕到「家长/公司」那一侧去。**

### 发现 3：失败者是成功者的 307 倍

| 豆瓣小组 | 成员数 |
|---|---|
| **「副业失败的一天」** | **414,572 人** |
| **「副业成功的一天」** | **1,350 人** |
| **比例** | **307 : 1** |

**这是本次调研最刺眼的一个数字。** 它说明：副业这件事，公开表达「失败」的人是「成功」的人的 307 倍。

## 五、⭐⭐ 那我到底该干什么（三选一）

### 路线 1：极低价走量（学生市场）

| 项 | 内容 |
|---|---|
| 价格带 | **30-100 元/单**（这是实测的真实区间，不是299） |
| 品类 | 简历修改（30-50）、课程作业辅导（不碰代写）、查重引导+降重方法 |
| 获客 | **必须投流**（闲鱼一天50预算≈10个咨询） |
| 天花板 | 月 3600 左右（自曝数据），做得好月 1-2 万（V2EX账本） |
| **风险** | **流量成本会吃掉利润**；学生单「性价比不高」是当事人原话 |

### 路线 2：做「付费方是家长/公司」的那一侧

| 项 | 内容 |
|---|---|
| 价格带 | **$200-300/小时**（家长市场）/ 国内升学咨询也有溢价空间 |
| 门槛 | **需要本地口碑、懂考试体系、家长转介绍** —— 中国人难做 |
| 国内版本 | 考研/留学咨询、志愿填报、家长付费的竞赛辅导 |
| **判断** | 天花板高但门槛也高，不建议作为第一站 |

### 路线 3：不做学生生意，改用这次学到的方法论做别的

| 学到的方法 | 可复用到哪 |
|---|---|
| 5维验真 / 打假三档 | 验证任何「月入X万」的项目 |
| 找真实账本（V2EX/论坛一手贴） | 任何生意的真实天花板 |
| 供需比计算（19:4） | 判断任何平台是否卖方过剩 |
| **付钱方分析（家长vs学生）** | **判断任何服务的真实定价权** |

**我的建议：如果要做，选路线 1 但把预期调到「月 3000-8000」，并且第一件事是测你的获客成本（投50块看能来几个人）。如果月获客成本 > 客单价，这生意对你不成立。**

## 六、⭐⭐ 这次调研最大的价值不是「发现了什么生意」

而是**验证了一套「怎么判断一个搞钱信息是真是假」的方法**：

| 步骤 | 做法 | 本例应用 |
|---|---|---|
| 1 | 追原始出处 | 「月入3.5万」→ 卖课号 |
| 2 | 看原文有没有自我否定 | 「真实性有待考证」 |
| 3 | 找反面证据 | 豆瓣失败组是成功组307倍 |
| 4 | 找价格矛盾 | 底册299 vs 实测30-50 |
| 5 | **找真实账本（最重要）** | V2EX 逐年逐月报数 |
| 6 | 看当事人现在还在做吗 | 半退出，因为流量要钱 |

**这套方法可以用在任何一个「月入X万」的诱惑上。**
