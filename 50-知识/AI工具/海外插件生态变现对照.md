# 海外插件生态怎么赚钱（DSH 可参考的对照）

> **DSH 生态 0 个付费插件。这轮看海外同类生态怎么做的。**
> **结论：没有一个是「直接卖插件」成功的。**

## 一、⭐⭐⭐ 三个生态的真实做法

### 1. VSCode（几十万插件）

| 事实 | 说明 |
|---|---|
| 插件数量 | 几十万 |
| **Volar 作者的经历** | **「做开源 4 年，被钱拖垮：无奈发起收费计划，竟遭恶意抨击」** |
| 说明什么 | **开源插件作者想收费，会遭遇社区抵制** |

### ⭐⭐ 关键引文（实测搜到的原文）

> **「如果不付费，要么是因为有人花了时间，要么因为这是营销策略」**

### 2. Obsidian（笔记工具）

| 事实 | 说明 |
|---|---|
| **商业模式** | **「Obsidian 本体免费，官方同步服务收费」** |
| 插件生态 | 社区插件免费 |
| **说明什么** | **钱不在插件上，在服务上** |

### 3. Chrome 扩展（最残酷）

| 事实 | 说明 |
|---|---|
| **重大事件** | **「谷歌 Chrome 应用商店突然宣布，永久禁用这类插件！」** |
| 原因 | **用来支持 Chrome 插件的每月订阅费和一次性付费** |
| **结果** | **付费插件被禁用** |

### ⭐⭐⭐ 这条最关键

> **「为什么谷歌突然宣布禁用所有付费插件，难道它不想赚钱了么？」**

**→ 平台方主动禁用了付费插件。**

## 二、⭐⭐⭐ 那他们怎么赚钱？（8 种方式）

**实测搜到的「Chrome 浏览器扩展插件的 8 种获利方式」：**

| # | 方式 | 例子 |
|---|---|---|
| 1 | **广告** | Adblock Plus（1 亿用户）靠广告获利 |
| 2 | **联盟营销** | Yieldkit（汇总会员计划） |
| 3 | CPU 挖矿 | CoinHive（体验很糟糕，已死） |
| 4 | 卖用户数据 | （不推荐） |
| 5 | **捐赠** | 常见 |
| 6 | **Freemium** | 基础免费 + 高级付费 |
| 7 | **订阅** | 但 Chrome 禁了 |
| 8 | **引流到自己的产品** | 最常见 |

## 三、⭐⭐⭐ 一个成功的个人案例

### 「一个人，一个插件，年收 54 万美元」

| 项 | 数据 |
|---|---|
| 收入 | **年 54 万美元**（约 390 万人民币） |
| 团队 | **一个人** |
| 产品 | **一个插件** |
| 来源 | 实测搜到的公众号文章标题 |

### ⚠️ 但要注意

**这是「案例」，不是「典型」。** 而且没看到它具体怎么收费。

## 四、⭐⭐ 另一个关键案例

### 「开发一个浏览器插件，在第三天卖出 1000 元」

| 项 | 数据 |
|---|---|
| 收入 | 第三天 1,000 元 |
| 关键引文 | **「国内的付费渠道接入门槛是相当高的」** |

**→ 国内付费有门槛（支付、合规）。**

## 五、⭐⭐⭐ 四个生态的对比

| 生态 | 插件能直接卖钱吗 | 实际怎么赚钱 |
|---|---|---|
| **Chrome 扩展** | ❌ **平台禁了付费** | 广告 / 联盟 / 引流 |
| **VSCode** | ⚠️ 可以但会挨骂 | 捐赠 / 公司支持 / 引流 |
| **Obsidian** | ❌ 插件免费 | **本体免费 + 服务收费** |
| **DSH** | ❓ **0 个付费插件** | 未验证 |

### ⭐⭐⭐ 一条共同规律

> **所有生态的「插件」本身都很难直接卖钱。**
> **钱在：广告 / 服务 / 引流 / 平台方（不是插件作者）。**

## 六、⭐⭐⭐ 对 DSH 的推论

| 推论 | 依据 |
|---|---|
| **① 直接卖插件大概率不行** | Chrome 禁了、Obsidian 免费、DSH 0 个付费 |
| **② 广告是最成熟的路** | Adblock Plus 1 亿用户靠广告 |
| **③ 引流到自己的服务最稳** | Obsidian「本体免费+服务收费」 |
| **④ 平台方赚钱，不是插件作者** | Chrome/Obsidian/VSCode 都是平台赚 |

### ⭐⭐ 一个残酷的结论

> **插件作者的定位是「给平台贡献内容」，不是「自己赚钱」。**
> **想赚钱，得把插件当「流量入口」，不是「产品」。**

## 七、⭐⭐ 那 DSH 的「平台方」是谁

| 角色 | 谁 |
|---|---|
| **平台本体** | DeepSeek 官方 |
| **目录站（赚广告）** | dshplugin.store、awesome、dshmarket 等 10+ 个 |
| **插件作者（你）** | 贡献内容，换流量 |

**→ 你已经看到：目录站靠 SEO + 广告赚钱（dshplugin.store 32,428 页）。**

**→ 而插件作者在给它们提供内容。**

## 八、⭐⭐⭐ 三条可参考的路（按可行性）

| 排名 | 路径 | 依据 | 难度 |
|---|---|---|---|
| **🥇 1** | **做目录站/内容站（当平台方）** | dshplugin.store 32,428 页 + 广告 | ⭐⭐⭐⭐ 高但已验证 |
| **🥈 2** | **做插件 → 引流到自己的服务** | Obsidian 模式 | ⭐⭐⭐ 中 |
| **🥉 3** | **做插件 → 放广告** | Adblock Plus 模式 | ⭐⭐⭐ 中 |
| ❌ | 直接卖插件 | 四个生态都没成功 | — |

### ⭐ 一个更聪明的角度

**既然目录站赚钱，而目录站需要内容——**

| 角色 | 你做什么 |
|---|---|
| **插件作者** | 给目录站贡献内容（免费） |
| **目录站** | 赚 SEO 流量 + 广告费 |
| **你如果做目录站** | **让别人的插件给你贡献内容** |

**→ 这是「从被平台抽成」变成「自己当平台」的路径。**
