# 成功率最高的三类：browser / model / vision 深挖

> **上轮发现这三类成功率最高（3.6% / 3.2% / 3.0%）。**
> **但这轮拆开看：它们也都很拥挤，零下载率 41-48%。**

## 一、⭐⭐⭐ 三类的真实情况

| 类别 | 总数 | 零下载 | 零下载率 | 成功（>1万） | 成功率 |
|---|---|---|---|---|---|
| **browser** | 139 | **57** | **41%** | 5 | 3.6% |
| **model** | 349 | **164** | **47%** | 11 | 3.2% |
| **vision** | 134 | **65** | **48%** | 4 | 3.0% |

### ⭐⭐ 一个矛盾

| 表面 | 实际 |
|---|---|
| 成功率最高（3-3.6%） | **但零下载率也高（41-48%）** |
| 说明「容易成功」 | **但「更容易失败」** |

**→ 这三类是「两极分化」：要么爆，要么死。**

## 五、⭐⭐⭐ 三类对比：该做哪个

| 类别 | 成功率 | 拥挤度 | 空白 | 建议 |
|---|---|---|---|---|
| **browser** | 3.6% | 中（139） | **PDF/视频处理** | ✅ **可做** |
| **model** | 3.2% | **高（349）** | 无（订阅接入已挤满） | ❌ **不建议** |
| **vision** | 3.0% | 中（134） | 无（看图已被占满） | ⚠️ **难做** |

### ⭐⭐⭐ 唯一明确的空白：browser + PDF

| 发现 | 数据 |
|---|---|
| browser 类里「PDF」只出现 | **3 次** |
| browser 类里「视频」只出现 | **5 次** |
| 但 PDF 是刚需 | 每个人都要处理 PDF |

**→ 「浏览器自动下载/解析 PDF」是个真空。**

## 六、⭐⭐ 具体可做的三个选题

### 选题 1：PDF 抓取器（browser 类）

| 项 | 内容 |
|---|---|
| 插件名 | `dsh-pdf-grabber` |
| 做什么 | **自动从网页抓取/下载 PDF，提取文本/表格** |
| 解决什么 | 「这个网页上有 PDF，但我要手动下载再转换」 |
| 依据 | browser 类里 PDF 只出现 3 次（真空） |
| 难度 | ⭐⭐⭐ 中（需要 PDF 解析库） |

### 选题 2：视频信息提取器（browser 类）

| 项 | 内容 |
|---|---|
| 插件名 | `dsh-video-digest` |
| 做什么 | **给一个视频链接，提取字幕/摘要** |
| 解决什么 | 「视频太长不想看」 |
| 依据 | browser 类里视频只出现 5 次 |
| 难度 | ⭐⭐⭐⭐ 高（需要处理视频/音频） |

### 选题 3：登录态管理（browser 类）

| 项 | 内容 |
|---|---|
| 插件名 | `dsh-login-manager` |
| 做什么 | **管理多个网站的登录态，自动填充** |
| 解决什么 | 「每次都要重新登录」 |
| 依据 | 「登录」出现 16 次（有需求但分散） |
| 难度 | ⭐⭐⭐ 中 |

## 七、⭐⭐ 我的判断

| 排名 | 选题 | 理由 |
|---|---|---|
| **🥇 1** | **PDF 抓取器** | 真空最明显（只 3 次） + 刚需 |
| 🥈 2 | 登录态管理 | 需求明确（16 次）但分散 |
| 🥉 3 | 视频信息提取 | 真空（5 次）但难度高 |
| ❌ | model 类 | 订阅接入已挤满（3 个 ChatGPT 接入） |
| ❌ | vision 类 | 看图已被占满（5 个） |
