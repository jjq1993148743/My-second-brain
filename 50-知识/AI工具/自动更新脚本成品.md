# 自动更新脚本已做好并实测通过

> **一条命令：抓数据 → 重算榜单 → 重新生成 HTML。**
> **实测跑通：6,378 插件，5 个榜单，全流程 40 秒。**

## 一、⭐⭐⭐ 为什么需要这个

| 问题 | 不更新的后果 |
|---|---|
| **数据会过期** | 榜单写着「2026-10-22」，一周后就是旧闻 |
| **搜索引擎不喜欢死站** | 不更新会降权 |
| **手动更新太累** | 每次要跑 5 个脚本 |

**→ 自动化是内容站能持续运营的前提。**

## 三、⭐⭐⭐ 脚本做什么

| 步骤 | 动作 |
|---|---|
| **1** | 从 awesome-dsh-plugin.com 抓 `plugins.json` |
| **2** | 重算 5 个榜单（下载/增速/机会/虚高/隐藏冠军） |
| **3** | 保存 `data.json`（29 KB） |
| **4** | 重新生成 `index.html` + `rankings.html` |
| **5**（可选） | `--push` 参数 → git commit + push |

## 四、⭐⭐ 两种用法

```bash
# 只更新本地（先看看效果）
node update.mjs

# 更新 + 直接推送上线
node update.mjs --push
```

## 七、⭐⭐ 怎么自动化（三种）

| 方式 | 说明 | 成本 |
|---|---|---|
| **① GitHub Actions** | 每天定时跑，自动 commit | 免费 |
| **② Windows 计划任务** | 本机每天跑 | 免费 |
| **③ 手动** | 想起来就跑一次 | 免费但会忘 |

### ⭐ 推荐 ①：GitHub Actions

```yaml
# .github/workflows/update.yml
name: Update rankings
on:
  schedule:
    - cron: '0 2 * * *'   # 每天 UTC 2 点（北京 10 点）
  workflow_dispatch:
jobs:
  update:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: '20' }
      - run: node update.mjs
        env:
          DSH_PROXY: ''   # GitHub Actions 不需要代理
      - run: |
          git config user.name 'github-actions'
          git config user.email 'actions@github.com'
          git add -A
          git diff --quiet || git commit -m 'chore: 更新榜单'
          git push
```

**⚠️ 注意：GitHub Actions 在海外，不需要代理，要把 `DSH_PROXY` 设成空字符串。**
