# 让 AI 执行更快 · 本机实测优化清单

> 结论先行：**PowerShell 7 和 WSL 都别装，实测更慢。** 真正的杠杆是持久终端会话 + 命令批处理，这两个已落地；剩下的在你这边（少让我追问、模型分级）。
> 采集背景：jjq 反馈"给你命令之后你执行比较慢"，要求给出可执行的环境优化方案。本笔记全部数字来自本机 2026-10-18 实测，非估算。

## 一、瓶颈定位（先看清慢在哪）

一次命令的总耗时 = **模型推理往返**（10–60 s，大头，压缩空间有限）+ **工具往返**（本次优化的主战场）。

| 环节 | 实测耗时 | 说明 |
|---|---|---|
| 模型推理 | 10–60 s | 占大头。每多一轮追问就多付一次 |
| pwsh 工具（每次新进程） | median 682 ms | 每条命令都重付进程启动 + 协议往返 |
| 持久终端会话 | median **124 ms** | 一次启动后续复用，**快 5.5 倍** |
| `read` 工具读文件 | **6 ms** | 比 shell 读快 99%，能用 read 就别用 cat/Get-Content |
| `grep` 搜内容 | median 538 ms | 比 PowerShell 遍历快 |
| 读全库 27 MB / 187 文件 | 5 ms | 磁盘完全不是瓶颈 |
| GitHub 网络 RTT | 1.7–2 s/次 | 仅 push / fetch 时发生 |
| 裸 PowerShell 进程启动 | median 198 ms | PS 5.1，与命令复杂度无关的固定门票 |

**关键认知：进程启动是"固定门票"，跟命令多复杂无关。** 分 10 条命令做一件事 = 白付 10 次门票（约 7 s），这些时间模型一秒都没用在思考上。

## 二、已验证的优化（已落地，AI 侧工作方式）

| 手段 | 收益（实测） | 做法 |
|---|---|---|
| **持久终端会话**替代逐条 pwsh | 682 → 124 ms，**省 82%** | 多步/有状态任务用 `terminal_open`，后续 `terminal_send` 复用 |
| **命令批处理** | 4 条命令 3.1 s → 0.9 s，**省 70%** | 一次调用做完一串相关操作，只 return 结论，中间过程不回传 |
| **能并行就并行** | 视任务 | 独立的只读调用同时发，不排队 |
| **优先用 read / grep** | 682 → 6 ms / 538 ms | 读文件、搜内容不走 shell |
| **大文件按需取片段** | 省 98.6% | `read` 带 offset/limit；同 [[省Token操作手册-可执行版]] 的思路 |

## 三、环境侧结论（jjq 侧，含否决项）

| 项 | 结论 | 依据 |
|---|---|---|
| **PowerShell 7** | ❌ **别装，实测更慢** | 空启动 287 ms vs PS 5.1 198 ms（慢 45%）；真实任务 717 ms vs 320 ms（慢 2.2 倍）。.NET 9 启动开销在 i5-10210U 上吃不消。且 DSH 的 pwsh 工具**硬编码** `System32\WindowsPowerShell\v1.0\powershell.exe`，装了也不走 |
| **WSL** | ❌ **别装** | ① 机器无 wsl.exe、虚拟化组件缺失，15.8 GB 内存跑 WSL2 偏紧；② WSL 只加速 Linux 命令，而瓶颈是模型往返，不对路；③ 跨 `/mnt/d` 访问 D 盘反而更慢，且会引入两套 git 凭证体系，更容易踩 [[Git 凭证弹窗反复出现（helper-selector）]] 的坑 |
| **Defender 排除 D:\GitHub** | ⏸ 未做，待 jjq 定 | 实时监控开启中，每次文件读写过扫描。需管理员权限且属安全权衡。不装也能干活 |
| **模型分级** | ⏸ 待 jjq 定 | 简单活用快模型，延迟可降 30–50%。在客户端层配置，AI 侧无法自主切换 |
| **便携 Git** | ✅ 已就位 | `C:\Users\赵青月\AppData\Local\Programs\Git\cmd\git.exe`（v2.56.0.windows.2，373 文件 / 91.7 MB）。注：这台机器**原本就装过**同一版本，重复安装的那份已删 |

## 五、给你的三条（收益最大，零成本）

1. **一次给足上下文**，别让我分多轮追问。每轮追问 = 一次完整模型往返（10–60 s）。"加载第二大脑"那次如果一开始就带对网址，能省 2–3 轮。
2. **一次交代一个完整目标**，不要"先做 A / 再改 B / 再看看 C"。我自己拆解执行顺序并批处理。
3. **能并行的明说**（"可以并行"），我会同时发多个子代理。
