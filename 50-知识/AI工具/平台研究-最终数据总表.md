## 六、方法论沉淀

### 5 维验真框架

1. **新鲜度** — 时间类型 + 年龄分布 + 今日新增
2. **竞争度** — 中位投标数
3. **预算水平** — 中位数而非平均
4. **项目质量** — 描述完整度、技术栈匹配
5. **平台可信度** — 第三方评价 + 费率透明度

### 6 步板块盘点（避免漏抓）

1. 首页导航栏有哪些一级入口？
2. 有没有 `/jobs` 之外的 `/careers` `/vakansii` `/positions`？
3. 有没有 `/contest` `/competition`？
4. 有没有 `/freelancers` 目录？
5. 有没有 `/hire` 雇主侧？
6. 分类页和主列表页是否内容不同？

**FL.ru 的教训：漏了职位板块 = 漏了 38% 的数据。**

## 七、技术要点汇总

| 情况 | 方案 |
|---|---|
| 普通站 | `curl -x http://127.0.0.1:7897` |
| SPA | Chrome `--dump-dom --virtual-time-budget=22000` |
| React 数据 | 找 `window.XXX.initialState=` 直接解析 |
| 分页无效 | 改用**分类 URL** |
| git push 失败 | `-c http.proxy=http://127.0.0.1:7897` |
| 正则含 `/` | 用字符类或转义，否则报 Invalid flags |
| 输出被查杀 | 用 `Out-File` 而非 `Tee-Object` |

2. **强制登录**（10+ 个）—— Upwork、CrowdWorks、Lancers、Coconala、task.epwk

5. **赏金类全封闭**（14 个）—— HackerOne、Bugcrowd、Algora 等
