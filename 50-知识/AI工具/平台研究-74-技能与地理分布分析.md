## 二、⭐⭐ 三个压倒性的方向

| 方向 | 次数 | 是第 4 名的倍数 |
|---|---|---|
| **ML/AI** | **826** | **18.8 倍** |
| **Security** | **414** | **9.4 倍** |
| **Data** | **259** | **5.9 倍** |
| Java（第 4） | 44 | 基准 |

**ML/AI、Security、Data 三个方向合计 1,499 次，占全部技能提及的 90%。**

### 这意味着什么

| 观察 | 含义 |
|---|---|
| ML/AI 是绝对主流 | 826 次，是 Java 的 19 倍 |
| 传统语言岗位少 | Java 44、Python 6、JavaScript 6 |
| **职位标题里很少写具体语言** | Python/React 只有个位数 |

**⚠️ 重要说明：这个统计只基于「职位标题」，不含职位描述。**

**所以「Python 只有 6 次」不代表 Python 岗位少，而是标题里不写。**

## 七、⚠️ 数据局限

| 局限 | 说明 |
|---|---|
| 只分析标题 | 不含职位描述，会低估具体语言需求 |
| 样本偏美国公司 | Greenhouse 客户以美国为主 |
| 公司不均衡 | Databricks 899 条 vs 小公司 2 条 |
| 地点是「办公室」不是「可远程」 | Remote 标记单独统计 |

## 八、结论

| 发现 | 数据 |
|---|---|
| **ML/AI 是第一需求** | 826 次（8%） |
| **Security 第二** | 414 次（4%） |
| **Data 第三** | 259 次（2.5%） |
| **Remote 是最大地点** | 1,751 条（17%） |
| **美国是最大国家** | 1,271 条（12%） |

### 一句话总结

**如果你想进入当前最热的行业：学 ML/AI 或 Security，然后找远程职位。**
