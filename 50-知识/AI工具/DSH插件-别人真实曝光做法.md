## 三、⭐⭐⭐ tnnevol 的做法（最值得学的结构）

| 项 | 内容 |
|---|---|
| 插件数 | 3+ |
| 统一文档站 | `fndsh-doc.tnnevol.cn` |
| URL 结构 | `/plugins/dsh-fnos`、`/plugins/dsh-codebuddy`、`/plugins/dsh-midscene.html` |
| 效果 | **所有插件统一导流到一个站，站内可以放广告/教程/引流** |

**这是「插件矩阵 → 统一入口」的打法。比每个插件单独建站省事，且流量集中。**

## 六、⭐⭐ 完整的真实曝光路径（别人验证过的）

```
1. 做插件（解决 DSH 真缺的功能）
2. 插件 homepage 字段填「你自己的站」（44 人这么做）
3. 站用 GitHub Pages 起步（21 人这么做，免费）
4. 有起色后换独立域名（15 人这么做）
5. 多插件就共用文档站（tnnevol 的做法）
6. 站里放：教程 + 你的公众号 + 广告位
7. 插件里放二维码（设置页/首次运行）
```
