# 整合站已做好：DSH Data Hub（3 个页面）

> **把榜单站 + 插件落地页合并成一个站，流量集中。**
> **3 个页面全部渲染验证通过。**

## 一、⭐⭐⭐ 为什么整合

| 之前 | 现在 |
|---|---|
| 2 个独立站（落地页 + 榜单站） | **1 个站 3 个页面** |
| 流量分散 | **流量集中** |
| 各站独立导航 | **统一导航** |
| 没有交叉引流 | **互相导流** |

| 页面 | 大小 | 内容 |

## 八、⭐⭐ 部署（3 步）

| 步 | 动作 |
|---|---|
| 1 | 建 GitHub 仓库 `dsh-data-hub` |
| 2 | 推 3 个 html |
| 3 | Settings → Pages → Source 选 `main` → Save |

**访问：** `https://你的用户名.github.io/dsh-data-hub/`

### ⚠️ 部署前必改

| 位置 | 改成 |
|---|---|
| `toolkits.html` 里所有 `YOUR_NAME` | 你的 GitHub 用户名 |
| 「公众号私信」的 `href="#"` | 你的二维码链接 |

## 九、⭐⭐ 这个站的商业逻辑

```
榜单页（内容，吸引流量）
   ↓ 用户来看「哪些插件值得装」
   ↓ 看到插件页
   ↓ 装我的 7 个插件
   ↓ 插件 README 里有公众号导流
   ↓ 公众号私域
   ↓ 变现
```

### ⭐ 关键设计

| 设计 | 目的 |
|---|---|
| **榜单在前（首页主推）** | 榜单是「内容」，更容易传播 |
| **插件在后（第二入口）** | 插件是「产品」，用户需要时再点 |
| **每页都有交叉链接** | 流量不流失 |
