# 做一个「销售」DSH 插件：完整可执行方案

> **依据：销售是 6,378 个插件里唯一 0 竞争的职业。**
> **参考样板：`dsh-network-engineer`（网络工程师）——零依赖、main=index.js、只需一个 cordis.patch.yml。**

## 一、⭐⭐ 先看别人的极简结构（这是最好的消息）

### `dsh-network-engineer` 的 package.json（实测）

| 字段 | 值 |
|---|---|
| name | dsh-network-engineer |
| version | 0.1.0 |
| **dependencies** | **`[]`（零依赖！）** |
| **main** | **`index.js`** |
| **dsh** | `{"bundle":{"patch":"./cordis.patch.yml"}}` |
| keywords | dsh, dsh-plugin, network-engineer, network, huawei, h3c, ruijie, dptech |

### ⭐⭐ 这说明了什么

| 事实 | 含义 |
|---|---|
| **零依赖** | 不用装任何 npm 包 |
| **main = index.js** | 一个文件就是全部代码 |
| **只需一个 cordis.patch.yml** | 声明式配置 |
| **内容是 32 篇知识库文档** | **核心工作量是写文档，不是写代码** |

**→ 做垂直职业插件，90% 的工作是「整理知识」，10% 是「写代码」。**

## 二、⭐⭐⭐ 销售插件：三个方案（选一个）

### 方案 A：话术库（推荐先做这个）

| 项 | 内容 |
|---|---|
| 插件名 | `dsh-sales-script` |
| 做什么 | 内置各行业销售话术 + 异议处理 |
| 知识库内容 | 见下表 |
| 技术难度 | ⭐ 最低（纯文档 + 简单调用） |
| 下载预期 | 参考 dsh-expert（636专家）451 下载 |

**知识库要准备什么（这是核心竞争力）：**

| 模块 | 内容 |
|---|---|
| **开场话术** | 电话开场、微信开场、拜访开场 |
| **需求挖掘** | SPIN 提问法、痛点引导 |
| **产品介绍** | FAB 法则（特性-优势-利益） |
| **异议处理** | 「太贵了」「再考虑」「已有供应商」等 20+ 场景 |
| **成交话术** | 假设成交、二选一、限时优惠 |
| **跟进话术** | 首次跟进、长期未回、节日问候 |
| **行业定制** | SaaS、制造业、保险、教育、房产 |

### 方案 B：跟进助手

| 项 | 内容 |
|---|---|
| 插件名 | `dsh-sales-followup` |
| 做什么 | 客户跟进提醒 + 自动生成跟进内容 |
| 技术难度 | ⭐⭐⭐ 中（要读数据+定时） |
| 功能 | ①客户列表（本地 JSON/SQLite）②到期提醒 ③一键生成跟进话术 ④跟进记录 |

### 方案 C：竞品分析

| 项 | 内容 |
|---|---|
| 插件名 | `dsh-sales-intel` |
| 做什么 | 竞品报价对比 + 卖点提炼 |
| 技术难度 | ⭐⭐⭐⭐ 高（要抓数据） |
| 功能 | ①竞品信息录入 ②对比表生成 ③差异化卖点提炼 |

## 三、⭐⭐ 方案 A 的完整开发清单

### 目录结构（参考 dsh-network-engineer）

```
dsh-sales-script/
├── package.json          # 零依赖，声明 dsh.bundle.patch
├── cordis.patch.yml      # 插件声明（注册工具/技能）
├── index.js              # 主逻辑（读知识库 + 提供工具）
├── README.md             # 说明 + 你的公众号
└── kb/                   # 知识库（核心资产）
    ├── opening.md        # 开场话术
    ├── discovery.md      # 需求挖掘
    ├── objection.md      # 异议处理
    ├── closing.md        # 成交话术
    └── industries/       # 行业定制
        ├── saas.md
        ├── manufacturing.md
        └── insurance.md
```

### package.json（照抄 dsh-network-engineer）

```json
{
  "name": "dsh-sales-script",
  "version": "0.1.0",
  "description": "销售话术库 for DeepSeek Harness：开场/需求挖掘/异议处理/成交，含行业定制",
  "main": "index.js",
  "keywords": ["dsh", "dsh-plugin", "deepseek-harness", "sales", "sales-script", "话术", "销售"],
  "dsh": { "bundle": { "patch": "./cordis.patch.yml" } }
}
```

### index.js 的核心逻辑（伪代码）

```javascript
// 1. 读取 kb/ 下的所有 markdown
// 2. 注册一个工具：sales_script(scenario, industry)
// 3. 根据参数返回对应话术
```

**真正的难点不是代码，是「知识库写得好不好」。**

## 四、⭐⭐ 内容从哪来（这是关键）

| 来源 | 怎么用 |
|---|---|
| **你自己的销售经验** | 最真实 |
| **公开销售书籍** | 《SPIN 销售法》《挑战式销售》 |
| **销售论坛/社群** | 真实案例（知乎、B 端销售群） |
| **AI 辅助整理** | 用 DSH 自己整理分类 |
| **访谈真实销售** | 最值钱（可以找 3-5 个销售朋友聊） |

**⚠️ 注意：不要直接抄别人的付费课程，要自己整理+原创表述。**

## 八、⭐ 时间预估（诚实）

| 阶段 | 时间 | 说明 |
|---|---|---|
| 写知识库 | **3-7 天** | 最花时间，但可以边写边发 |
| 写代码 | **1-2 天** | 参考极简结构 |
| 打包发布 | **半天** | npm publish |
| 提交 9 个站 | **1 天** | 逐个提交 |
| 曝光发酵 | **1-4 周** | 等日报抓取/用户发现 |

**总计：1-2 周可以上线，1 个月看效果。**

## 九、⚠️ 风险与诚实预期

| 风险 | 说明 |
|---|---|
| **可能没人装** | 销售人群可能不用 DSH |
| **下载量可能很低** | 参考 dsh-expert（636专家）只有 451 下载 |
| **变现路径未验证** | 全生态 0 个付费插件 |
| **知识库质量决定成败** | 话术不实用就没人用 |
| **要持续维护** | 话术要更新 |

### ⭐ 但下行风险很低

| 项 | 说明 |
|---|---|
| 投入 | 1-2 周业余时间 |
| 成本 | **0 元**（npm 免费、GitHub 免费） |
| 最坏结果 | 一个作品 + 一次完整实践 |
| 最好结果 | 几百到几千下载 + 一批销售粉丝 |
