# 验证：配置迁移这个方向到底空不空

> **上一轮我说「配置迁移是真空」，这轮用 7 种文件格式逐个验证。**
> **结论：`.cursorrules` 和 `.windsurfrules` 确实是 0，但 Skills 和 MCP 已被占。**

| 格式 | 提及插件数 | 判断 |
|---|---|---|
| **`.cursorrules`** | **0** | ✅✅ **完全空白** |
| **`.windsurfrules`** | **0** | ✅✅ **完全空白** |
| **CLAUDE.md** | **5** | ✅ 少 |
| **prompts（提示词模板）** | **6** | ✅ 少 |

| **mcpServers** | **64** | 🔴 红海 |

### ⭐⭐ 三个关键发现

| 发现 | 说明 |
|---|---|
| **`.cursorrules` 0 个** | Cursor 的规则文件，**没人做迁移** |

| **Skills 已被 skills-management 占领** | 它「一键收编本机所有 coding agent 的技能」 |

## 三、⭐⭐⭐ 真正的空白：`.cursorrules` / `.windsurfrules` 迁移

### 为什么这是空白

| 事实 | 说明 |
|---|---|
| **Cursor 用户很多** | 全球最流行的 AI IDE 之一 |
| **Windsurf 用户不少** | 另一个流行 AI IDE |
| **规则文件是核心资产** | 用户花时间写的项目规则 |
| **迁移是刚需** | 从 Cursor 转 DSH 时要带走规则 |
| **0 个插件做** | 完全空白 |

### ⭐ 但要注意一个风险

| 风险 | 说明 |
|---|---|
| **`dsh-agent-instructions-editor` 可能已部分覆盖** | 它能编辑 agent 指令，可能支持导入 |
| **规则文件格式很简单** | 就是 markdown，用户手动复制也行 |
| **可能不是强需求** | 手动复制 5 秒就能完成 |

**→ 这是最大的疑问：如果手动就能做，为什么要装插件？**

## 四、⭐⭐ 让我重新想：什么才是「手动做不到」的？

| 手动能做的 | 手动做不到的 |
|---|---|
| 复制 .cursorrules 到 AGENTS.md | **批量迁移多个项目** |
| 复制 CLAUDE.md | **自动检测项目里有哪些规则文件** |
| 复制提示词 | **合并冲突的规则** |
| 复制 SKILL.md | **转换格式差异**（如果格式不同） |
| 填 MCP 配置 | **验证迁移后的配置能用** |

### ⭐⭐⭐ 真正的价值点

| 价值点 | 说明 |
|---|---|
| **批量** | 一次性迁移 10 个项目 |
| **自动发现** | 扫描磁盘找出所有 .cursorrules |
| **格式转换** | Cursor 规则 → DSH AGENTS.md 的格式差异 |
| **冲突合并** | 多来源规则合并 |
| **验证** | 迁移后检查是否生效 |
