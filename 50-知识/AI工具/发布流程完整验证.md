### ⚠️ npm publish 可能遇到的问题

| 问题 | 原因 | 解决 |
|---|---|---|
| **包名被占用** | 已有人注册 `dsh-sales-script` | 改成 `@你的用户名/dsh-sales-script` |
| 需要 2FA | npm 账号开了双因素 | 输入 OTP |
| 权限不足 | 账号未验证邮箱 | 验证邮箱 |
| **首次发布需要 --access public** | 默认私有 | 加 `--access public` |

## 六、⭐ 如果 npm 包名被占用怎么办

**最可能的情况**：`dsh-sales-script` 这种通用名可能已被占。

**解决方案：用 scoped 包名**

```json
"name": "@你的用户名/dsh-sales-script"
```

**然后安装命令也变：**
```bash
dsh plugin --profile desktop add @你的用户名/dsh-sales-script
```

**scoped 包名的好处：**
| 好处 | 说明 |
|---|---|
| **不会撞名** | 只有你能用 @你的用户名/* |
| **便于识别** | 一看就知道是你的 |
| **可批量** | 6 个插件都叫 @你的用户名/dsh-xxx |

**⚠️ 建议直接用 scoped 包名，避免撞名风险。**
