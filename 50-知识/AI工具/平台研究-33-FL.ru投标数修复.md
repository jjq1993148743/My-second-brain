# 平台研究 #33 · FL.ru 投标数解析修复【重大修正】

> **之前的 FL.ru 报告说「中位投标 30-50 人，竞争激烈」。**
> **这一轮修好了解析器，发现真实中位数是 11 人 —— 只有原来估计的 1/3。**

## 一、修复了什么

### 问题

之前的解析器没有抓 `offers` 字段（显示为 0 条有数据）。

### 原因

**FL.ru 的投标数格式是俄语：`7 ответ`（ответ = 回复）**

```
之前找的是: отклик/ставк/предложен  ❌
实际格式是: N ответ  ✅
```

### 修复后

| 指标 | 修复前 | **修复后** |
|---|---|---|
| 有投标数据 | 0 条 | **562 条（89%）** |
| 中位投标 | 未知（估计 30-50） | **11 人** |

## 八、这个修复的意义

### 方法论教训

**当解析结果全为空（0 条）时，不要假设「平台没有这个字段」，要怀疑「解析规则错了」。**

| 情况 | 正确做法 |
|---|---|
| 字段全空 | ❌ 假设平台没这个数据 |
| 字段全空 | ✅ **去原始 HTML 里搜可能的格式** |

**这次就是在原始 HTML 里搜 `отклик|ставк` 无果，搜 `ответ` 才发现。**

**修复的代码：**

```javascript
// 之前（错）
const om = chunk.match(/(\d+)\s*(?:отклик|ставк|предложен)/);

// 现在（对）
const om = chunk.match(/(\d+)\s*ответ/);
const offers = om ? +om[1] : null;
```
