# 免费大模型接入方案 · 调研

> 2026-10-09 ｜ 目的：找"把问题丢给网页端千问等免费 AI"的方案

## 结论先行

你要找的东西**确实存在**，叫 **freechat 系列**（浏览器自动化驱动网页版 AI）。
**但它踩你自己的红线**（AGENTS.md §0.1：绝不封号/封 IP）——**我不建议用**。

## 三个方案对比

| 方案 | 代表 | 成本 | 封号风险 | 推荐 |
|------|------|------|----------|------|
| ① 浏览器自动化 | `freechat-deepseek` | 0 | **高（违反平台 ToS）** | ❌ |
| ② 免费 API | `free-llm-cn-skill` | 0（额度内） | 低（官方授权） | ✅ |
| ③ 本地模型 | Ollama + 开源模型 | 0（电费） | 无 | ✅ |

---

## 方案① 浏览器自动化（你听说的那个）

**`freechat-deepseek`** —— cocoloop / ClawHub 商店，基于 **openclaw** 浏览器框架。

- **机制**：打开 `chat.deepseek.com` → 扫码登录 → 输入问题 → 从 DOM 提取回复。全程不走 API。
- **别名**：`chat-deepseek` / `ask-deepseek` / `browse-deepseek` / `deepseek-search`
- **优点**：零 API 成本、复用网页免费额度、多通道推送（iMessage/WhatsApp/QQBot/飞书/企微/Slack）、支持 DeepThink 模式
- **风险（它官方文档自己写的）**：
  - 扫码登录需人工配合，2 分钟超时
  - DOM 选择器**脆弱**，页面改版即失效
  - 高频调用触发 **429 / 反爬**
  - **"自动化工具可能违反 DeepSeek ToS，导致账号受限"** ← 踩红线
  - 无文件上传
- **未找到确证的"千问版"**（只确证了 DeepSeek 版）

**为什么我不建议**：这个方案省的是"API 钱"，赌的是"账号"。你 AGENTS.md 白纸黑字写着"绝不封号"，不值得为省这点钱去冒险。

## 方案② 免费 API（推荐）

**`free-llm-cn-skill`**（GitHub: `kwon85428-art/free-llm-cn-skill`）—— 专为 WorkBuddy 做的。

据其仓库介绍，三个平台的免费额度：

| 平台 | 免费模式 | 代表免费模型 |
|------|----------|--------------|
| 阿里百炼 DashScope | 每模型 100 万 token / 90 天 | qwen-plus、qwen3-coder-flash |
| SiliconFlow 硅基流动 | 一批模型**永久免费** | Qwen3-8B、GLM-Z1-9B |
| 智谱 BigModel | 7 个 flash **永久免费** | glm-4.7-flash、glm-z1-flash |

共 28 个模型配置（阿里 13 + SiliconFlow 8 + 智谱 7）。

**装法**：SKILL.md + scripts 放进 `~/.workbuddy/skills/free-llm-cn/`，按文档把 JSON 片段追加到 `~/.workbuddy/models.json`，重启 WorkBuddy。
**验证**：`python scripts/test_cn_free.py`（自动读真实 Key，只打印状态码，不打印 Key）。

> ⚠️ 本机实际用的是 `~/.workbuddy-ai/skills/`（带 -ai），路径以官方文档为准。

**优点**：官方免费额度、**不违反 ToS、不封号**、走标准 API、稳定。
**代价**：额度有限（用完要付费或换平台）；不是"网页端"，但你本来就是要在 agent 里用，API 更顺。

---

## 方案③ 本地模型（最稳）

Ollama + 开源模型（Qwen 开源版、GLM 等），**完全免费、不封号、不联网**，代价是要本地算力。

---

## 我的建议

**走方案②（免费 API），别碰方案①（浏览器自动化）。**

理由：方案② 是官方给的免费额度，合规、稳定；方案① 用自动化去薅网页免费额度，**平台明确反对**，随时可能连号一起收走。
