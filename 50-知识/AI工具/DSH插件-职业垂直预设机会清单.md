## 六、⭐⭐ 我的推荐：做「销售」

| 理由 | 说明 |
|---|---|
| **零竞争** | 0 个插件 |
| **人群巨大** | 中国有数千万销售从业者 |
| **痛点明确** | 话术、跟进、报价、竞品 |
| **付费意愿** | 销售直接和业绩挂钩，愿为提效付费 |
| **技术门槛低** | 主要是提示词工程 + 模板库 |
| **容易导流** | 销售社群密集（企微群、钉钉群） |

### ⭐ 具体做什么（三个方向选一个）

| 方向 | 插件名 | 功能 |
| **① 话术库** | `dsh-sales-script` | 内置各行业销售话术 + 异议处理 |
| **② 跟进助手** | `dsh-sales-followup` | 客户跟进提醒 + 自动生成跟进内容 |
| **③ 竞品分析** | `dsh-sales-intel` | 竞品报价对比 + 卖点提炼 |

## 七、⭐ 为什么「职业预设」是好的插件方向

| 优势 | 说明 |
|---|---|
| **技术门槛低** | 主要是写文档/知识库/提示词，不需要复杂代码 |
| **差异化强** | 每个职业独立赛道，不互相挤 |
| **可复制** | 做完一个职业，可以做第二个 |
| **人群精准** | 职业人群有明确聚集地 |
| **已验证** | dsh-network-engineer（网络工程师）355 下载、dsh-expert（636位专家）451 |
