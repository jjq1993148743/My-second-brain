## 三、⭐⭐⭐ 你要做的全部（6 步，约 2 小时）

### 第 1 步：改名字（2 分钟）

在 `D:\GitHub` 下执行：

```bash
node publish-all.mjs 你的GitHub用户名
```

会依次处理三个插件，改掉 YOUR_NAME，并显示每个插件的 git 命令。

### 第 2 步：建 3 个 GitHub 仓库（20 分钟）

**先在网页上建三个空仓库**（不要勾选初始化 README）：

| 仓库名 |
|---|
| `dsh-sales-script` |
| `dsh-hr-toolkit` |
| `dsh-legal-toolkit` |

然后对每个目录执行（命令脚本已给你）：

```bash
cd D:\GitHub\dsh-sales-script
git init
git add .
git commit -m "feat: dsh-sales-script v0.1.0"
git branch -M main
git remote add origin https://github.com/你的用户名/dsh-sales-script.git
git push -u origin main
```

### 第 3 步：发 npm（15 分钟）

```bash
npm login
# 输入用户名/密码/邮箱/OTP

cd D:\GitHub\dsh-sales-script && npm publish --access public
cd D:\GitHub\dsh-hr-toolkit && npm publish --access public
cd D:\GitHub\dsh-legal-toolkit && npm publish --access public
```

**验证地址：**
- `npmjs.com/package/dsh-sales-script`
- `npmjs.com/package/dsh-hr-toolkit`
- `npmjs.com/package/dsh-legal-toolkit`
