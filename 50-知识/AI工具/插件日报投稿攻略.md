## 二、⭐⭐⭐ 日报的实际写法（三种格式）

### 格式 1：黑鲸鱼/Rubbish Science（列表式）

```
DSH 插件日报 · 2026-10-19（附详细名单）

昨晚到今晚，DSH 插件库又蹿出 280 个新仓库。
我顺着名单翻了一圈，生态明显在往两个方向长。
界面和协作类还是大头。桌宠、壁...

zangoose335/dsh-todo-assistant ★0 — 会话中记录待办，并自动沉淀相关上下文
Nicolas-One/dsh-dsml-reasoning-guard ★0 — 从推理内容里捡回被藏起来的工具调用
hx95270000-lang/dsh-mc-bridge ★0 — Minecraft 控制桥
```

**格式：`owner/repo ★星数 — 一句话说明`**

**⚠️ 注意：它们连 ★0 的插件都写！** 说明门槛不高，但要有「一句话说清」的价值。

### 格式 2：一个程序员的宇宙观（分类式）

```
DeepSeek Harness 插件日报 2026 年 10 月 18 日

今日总览：过去 24 小时（UTC 10-16 22:...）
高热度与金融专项
```

**特点：有「总览」+「分类专项」（如金融专项）**

### 格式 3：技术宅SuperLaos（周榜式）

```
DSH 插件周榜 - Week 43 - 2026.10.19

#DSH插件 #插件周榜 #桌面端 #终端界面 #多智能体 ...
```

**特点：按周汇总 + 打标签**

## 三、⭐⭐⭐ 被日报选中的 5 个条件（从内容反推）

| 条件 | 证据 |
|---|---|
| **① 能用一句话说清价值** | 所有日报都是「一句话说明」格式 |
| **② 有具体场景** | 「会话中记录待办」「让 agent 进 Minecraft」 |
| **③ 零依赖更好** | Rubbish Science 写「昔涟的长期记忆插件（DSH 0.2.1+，**零依赖**）」 |
| **④ 新仓库优先** | 日报都是「昨晚到今晚新增」 |
| **⑤ ★0 也写** | 说明不看重 star |

### ⭐⭐⭐ 最重要的发现

> **日报的核心工作流是「扫描 GitHub 新增仓库」→「挑有价值的写一句话」。**
> **它们连 ★0 都写，说明门槛是「一句话说清价值」，不是「有多少 star」。**

**→ 你的插件只要：①在 GitHub 上 ②README 有一句话价值 ③打 dsh-plugin 标签，就可能被扫到。**

## 四、⭐⭐ 提高被采用概率的 6 个方法

### 方法 1：README 第一行写「一句话价值」

**日报作者扫描时只看 README 开头。**

| ❌ 差 | ✅ 好 |
|---|---|
| 「销售话术库 for DeepSeek Harness」 | **「客户说『太贵了』时，直接给出 5 步应对话术」** |
| 「HR 工具箱」 | **「30 秒判断简历值不值得面试」** |
| 「法律工具箱」 | **「合同审查 7 大类 42 项清单，逐条打勾」** |

### 方法 2：仓库描述（description）也要写清

**GitHub 仓库描述是日报抓取的第一手信息。**

现在我们的 description：

| 插件 | 当前 description |
|---|---|
| 销售 | 「销售话术库 for DeepSeek Harness：开场/需求挖掘/异议处理/成交/跟进，含行业定制与中文销售场景」 |
| HR | 「HR 工具箱 for DeepSeek Harness：简历筛选/面试提问/JD生成/offer谈判/员工沟通，含行业定制」 |

**建议改成更抓人的：**

| 插件 | 建议 description |
|---|---|
| 销售 | 「客户说『太贵了』时给出 5 步应对话术 · 20+ 异议场景 · 5 个行业定制」 |
| HR | 「30 秒判断简历值不值得面试 · STAR 面试题库 · 5 个行业定制」 |

### 方法 3：打全标签

```bash
gh repo edit --add-topic dsh-plugin --add-topic dsh --add-topic deepseek-harness \
  --add-topic sales --add-topic crm --add-topic chinese
```

**建议每个插件打 5-6 个标签。**

### 方法 4：主动投稿（附「一句话」）

**投稿时直接给它能复制的内容：**

```
你好，投一个插件：

你的用户名/dsh-sales-script ★0 — 客户说「太贵了」时给出 5 步应对话术，含 20+ 异议场景和 5 个行业定制

（如果合适，可以直接用这行）
```

**⚠️ 关键：格式对齐它们的写法（owner/repo ★N — 一句话）**

### 方法 5：挑「新增仓库」的时间窗口

**日报都是「昨晚到今晚新增」，所以你发布后 24-48 小时内是被扫到的最佳窗口。**

| 时机 | 做法 |
|---|---|
| 发布当天 | 打标签（让它在「新增」里） |
| 24 小时内 | 主动投稿（趁新鲜） |
| 3 天后 | 如果没被写，再投一次 |

### 方法 6：蹭「分类专项」

**一个程序员的宇宙观有「金融专项」，说明它会按行业分类。**

**→ 投稿时说明你的插件属于哪个垂直领域：**

| 插件 | 投稿时说 |
|---|---|
| 销售 | 「销售/CRM 垂直」 |
| HR | 「招聘/HR 垂直」 |
| 律师 | 「法律垂直」 |
| 教师 | 「教育垂直」 |
| 财务 | 「**金融垂直**」（对应它的金融专项！） |
| 运营 | 「运营/内容垂直」 |

**⭐ 财务插件最容易上「金融专项」。**
