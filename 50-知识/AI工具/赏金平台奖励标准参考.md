## 一、补天（butian.net）奖励标准

**来源**：https://www.butian.net/Reward/pub（公开页面）

| 厂商规模 | 库币奖励 | 现金等值 |
|---|---|---|
| 小型厂商 | 4–20 库币 | ¥100–200 |
| 中型厂商 | 6–25 库币 | ¥100–1,000 |
| 大型厂商 | 10–30 库币 | ¥100–500 |

| 厂商规模 | 现金奖励 |

| 大型厂商 | ¥100–2,000 |

## 二、与海外赏金平台对比

| 平台 | 低危 | 高危 | 严重 | 备注 |
|---|---|---|---|---|
| **补天（国内）** | ¥100–200 | ¥800–3,000 | **¥3,000–10,000** | 人民币结算 |
| HackerOne（海外） | $100–500 | $1,000–5,000 | **$10,000–50,000+** | 美元结算，需英文 |
| Bugcrowd（海外） | $100–1,000 | $2,000–10,000 | $10,000+ | 同上 |

**结论：国内赏金天花板约 ¥10,000（$1,400），海外可达 $50,000+（¥36 万）。差 25 倍。**

## 四、结论

### 赏金类平台的现实

| 类别 | 数量 |
|---|---|
| 可公开看到实时列表 | **0 个** |
| 只能看奖励标准 | 1 个（补天） |
| 需要登录/邀请 | 大部分 |

**核心障碍：赏金平台的漏洞/任务列表都是「登录后可见」，这是行业惯例。**

### 可行的替代路径

1. **GitHub 赏金**：Algora 的 issue 在 GitHub 上公开，可用 GitHub API 抓
2. **开源悬赏**：IssueHunt 的项目在 GitHub 上，同样可抓
3. **补天/漏洞盒子**：注册后可以看到，但需要实名

### 价格参考价值

**补天的价格标准至少告诉了我们：**
- 国内安全赏金天花板 ¥10,000
- 海外（HackerOne）可达 $50,000+
- **如果要做赏金，出海比国内值 25 倍**
