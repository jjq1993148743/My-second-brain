## 四、最终建议

### 🥇 第一优先：一品威客

**理由：**
- 竞争最小（中位 1 人投标）
- 预算最高（中位 ¥3,200，是 PPH 的 4.5 倍）
- 开发类占 63%（最高）
- 已验证真实（截稿时间在未来）
- 中文无障碍

**待做：**
1. 注册账号，验证抽成规则（官方 19 条规则未公布）
2. 确认「直接雇佣免抽佣」的具体条件
3. 挑 3-5 个投标 ≤2 的项目试投

### 🥈 第二优先：FL.ru（如果你会俄语）

**理由：**
- 最新鲜（中位 6 小时，18% 在 1 小时内）
- 开发类 34%
- 俄语壁垒挡住大部分竞争者

**门槛：** 俄语 + PRO 账号 + Bitrix/1C 技能 + 信誉积累

### 🥉 情报源（不接单）：PeoplePerHour / Freelancer 系

**用途：** 了解全球市场价格水平，不做主要投入。

### ❌ 排除：猪八戒

**原因：** 100% 是 1-3 年前的僵尸项目。

## 六、方法论沉淀

### 6 步识别僵尸项目

1. 查时间字段类型（相对时间可信，绝对日期需验证）
2. 算年龄分布（看中位数，不看最新一条）
3. 看今天发布数量（0 条 = 危险）
4. 交叉验证状态字段（3 年前项目还标进行中 = 矛盾）
5. 验证竞争度异常（低竞争 + 陈旧 = 双重信号）
6. 看截稿时间（比发布时间更直接）

### 技术要点

| 情况 | 用什么 |
|---|---|
| 普通站 | `curl -x http://127.0.0.1:7897` |
| SPA 站 | Chrome headless + `--virtual-time-budget=22000` |
| 数据在 React 里 | 找 `window.XXX.initialState=` 直接解析 |
| git push 失败 | 加 `-c http.proxy=...` |
| 正则含 `/` | 用字符类或转义，否则报 Invalid flags |
