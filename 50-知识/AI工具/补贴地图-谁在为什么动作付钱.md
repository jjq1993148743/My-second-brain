# 补贴地图 · 谁在为什么动作付钱

> **方法论转向：不再问「哪里能接活」，改问「谁在付钱买什么动作、付多少」。**
> **这张图里的每一条，都是『一个动作 = 一笔钱』，且不写在任何招聘平台上。**
> **来源：内部行业知识梳理。每条都需要后续实测验证（标注了验证方式）。**

## 一、⭐⭐ 核心洞察：搞钱信息分三层

| 层 | 内容 | 获取方式 | 竞争 | 我之前做了什么 |
|---|---|---|---|---|
| **L1 面上** | 平台名单、公开报价 | 搜索、抓取 | 极高 | ❌ 我 90% 时间耗在这 |
| **L2 半隐性** | 真实账本、从业者复盘 | 定向深挖论坛/社群 | 中 | ✅ 只做过一次（V2EX） |
| **L3 隐性** | **渠道返佣、补贴套利、制度性资金** | **行业知识 + 内部社群 + 推理** | **低** | 🔴 **零** |

**你举的「运营商开卡返现」就是 L3。** 它不在任何平台上，但在运营商-渠道商-地推的链条里真实存在。

## 二、⭐⭐ 补贴地图：按「钱从哪来」分类

### 💰 A. 企业获客预算（最普遍，最容易上手）

| 动作 | 谁付钱 | 返佣量级（行业经验值） | 验证方式 |
|---|---|---|---|
| **办一张手机卡** | 运营商 | ¥30-150/张 | 任务墙实测 |
| **办一条宽带** | 运营商 | ¥50-200/条 | 地推平台 |
| **办一张信用卡** | 银行 | ¥50-300/张（核卡/首刷） | 地推接单平台 |
| **开一个证券账户** | 券商 | ¥30-200/户 | 券商合作渠道 |
| **开一个二类户/数字人民币** | 银行 | ¥10-50/户 | 银行活动 |
| **注册并激活某 App** | 各类平台 | ¥5-50/个 | 任务墙 |
| **外卖/打车首单** | 美团/滴滴 | ¥10-30/人 | 拉新活动 |
| **电商平台新用户下单** | 拼多多/京东 | ¥5-30/人 | 拉新活动 |
| **办理 POS 机** | 支付公司 | 机器佣金 + 流水万3-万8 分润 | 支付代理商 |
| **ETC 办理** | 银行/高速 | ¥30-100/台 | 地推 |

**这一类的共同点：企业有明确的单客获客成本（CAC），愿意把钱分给带来客户的人。**

### 🏛️ B. 政策补贴（制度性资金，金额最大）

| 动作 | 谁付钱 | 金额量级 | 中介抽成 |
|---|---|---|---|
| **高新企业认定** | 政府 | 补贴 20-100 万 | 10-15% |
| **研发费用加计扣除** | 税务 | 按研发投入比例 | 服务费 |
| **专精特新申报** | 政府 | 数十万 | 10-20% |
| **灵活用工/税收洼地** | 地方园区 | 按节省税额分成 | 分成制 |
| **创业补贴/社保补贴** | 人社 | 数千-数万 | 服务费 |
| **残疾人就业加计扣除** | 税务 | 按人数 | 服务费 |
| **大学生创业扶持** | 政府 | 数千-数十万 | 服务费 |

**这一类门槛高（要懂政策、会写材料），但单笔金额最大。**

### 🎯 C. 平台补贴与价差套利

| 动作 | 谁付钱 | 收益逻辑 |
|---|---|---|
| **跨平台搬砖** | 平台差价 | 拼多多低价 → 闲鱼/淘宝加价 |
| **百亿补贴套利** | 平台补贴 | 补贴价买入 → 市场价出 |
| **信用卡积分/航空里程** | 银行/航司 | 刷卡积分 → 兑换 → 转卖 |
| **新户/首单优惠** | 平台 | 用新人价买 → 正常价卖 |
| **话费/流量充值折扣** | 运营商渠道 | 慢充 92-97 折 买入 |
| **加油卡/超市卡折扣** | 渠道商 | 95-98 折进出 |
| **游戏点卡/充值卡折扣** | 渠道 | 折扣买卖 |

### 🔄 D. 硬通货价差（发行价 vs 市场价）

| 品类 | 机制 | 风险 |
|---|---|---|
| **茅台等白酒** | 1499 发行价 vs 2000+ 市场价 | 中（需渠道） |
| **纪念币/纪念钞** | 面值预约 vs 溢价转卖 | 低 |
| **限量球鞋** | 发售价 vs 二级市场 | 中 |
| **演唱会门票** | 官方价 vs 黄牛价 | 🔴 高（法律风险） |

### 🧩 E. 流程代办（流程复杂=收费理由）

| 动作 | 客户 | 收费 |
|---|---|---|
| **陪诊** | 老人/异地就医 | ¥100-300/次 |
| **代挂号** | 患者 | ¥50-200 |
| **落户咨询代办** | 新市民 | ¥1000-10000 |
| **法拍房尽调** | 购房者 | ¥2000-10000 |
| **商标注册代理** | 小微企业 | ¥300-1000 |
| **公司注册/记账** | 创业者 | ¥500-3000/年 |

## 三、⭐⭐ 怎么验证这张图（下一步动作）

| 优先级 | 验证方式 | 能拿到什么 |
|---|---|---|
| **1** | 实测任务墙平台（趣闲赚/悬赏猫类） | 直接看到「什么动作=多少钱」的明码标价 |
| **2** | 实测地推接单平台 | 信用卡/运营商/App拉新的真实报价 |
| **3** | 搜 CPA 广告联盟价目 | 一个注册/一个申请多少钱 |
| **4** | 看公开线报频道 | 实时的一手信息 |

## 四、⚠️ 红线（这类生意灰产最多）

| 灰产 | 为什么不能碰 |
|---|---|
| **批量开卡/养号** | 违反实名制，涉帮助信息网络犯罪 |
| **接码平台** | 为黑产提供工具 |
| **刷单/虚假交易** | 违法 |
| **买卖账号** | 违反平台规则+法律 |
| **信用卡套现** | 非法经营 |
| **黄牛倒票** | 治安管理处罚法 |

**合规部分：你自己真实办理+正规渠道推广（一人一卡、真实用户）。**

## 五、这份地图怎么用

| 如果你是… | 优先看 |
|---|---|
| 想快速见钱 | A 类（获客预算）——任务墙当天就能接 |
| 有企业资源 | B 类（政策补贴）——单笔最大 |
| 有流量 | C 类（平台价差）——可规模化 |
| 有耐心 | E 类（流程代办）——复购稳定 |
