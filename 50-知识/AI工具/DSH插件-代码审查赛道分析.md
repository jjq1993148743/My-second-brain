## 六、⭐⭐ 更重要的发现：这个赛道教我什么

### ⭐⭐⭐ 「同名插件」是个陷阱

| 现象 | 说明 |
|---|---|
| **3 个插件都叫 `dsh-code-review`** | 但 npm 包名不同 |
| **索引里看不出来** | 只能看到名字和下载量 |
| **我差点误判** | 以为只有 1 个，实际 3 个 |

**→ 判断赛道拥挤度，必须看 npm 包名，不能只看插件名。**

### ⭐ 教训汇总（这几轮我犯的错）

| 错误 | 教训 |
|---|---|
| 用 849 索引代替 6378 全量 | 用最大数据源 |
| 只看描述不看 npm keywords | 查 npm |
| 只看插件名不看 npm 包名 | **同名插件可能是不同产品** |
| 「0 个」就以为是空白 | 反问「为什么是 0」 |
