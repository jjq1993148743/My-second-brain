## 七、⚠️ 数据说明

| 项 | 说明 |
|---|---|
| 增速算法 | 下载量 ÷ 上线天数（粗略估算） |
| **局限 1** | **假设下载是均匀分布的**（实际可能前期快后期慢） |
| **局限 2** | 老插件的日均会被「早期积累」拉高 |
| **局限 3** | 上线 3 天内的不算（避免虚高） |
| 下载量口径 | 该站统计的 npm 下载 |
