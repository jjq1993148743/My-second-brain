## 四、⭐⭐⭐ 为什么做三个（矩阵策略）

| 理由 | 说明 |
|---|---|
| **共享同一套架构** | index.js 逻辑完全一样，只换知识库 |
| **边际成本极低** | 第一个做完，后面每个只需写知识库 |
| **互相导流** | README 里可以互相推荐 |
| **覆盖不同人群** | 销售/HR/律师 三个职业群 |
| **提高曝光概率** | 三个插件三次被日报抓的机会 |

### ⭐ 成本对比

| 插件 | 开发时间（估算） |
|---|---|
| 第一个（销售） | 约 2 小时（含架构设计） |
| 第二个（HR） | 约 40 分钟 |
| 第三个（律师） | 约 40 分钟 |

**→ 边际成本递减，这就是矩阵的价值。**
