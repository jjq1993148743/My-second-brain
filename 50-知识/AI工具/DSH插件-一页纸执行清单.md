### 最小插件结构

```
your-plugin/
├── package.json          # 零依赖 + dsh 字段
├── cordis.patch.yml      # 插件声明
├── index.js              # 主逻辑
├── README.md             # 说明 + 你的公众号
└── kb/                   # 知识库（核心资产）
```
