# DSH 插件曝光机制全解（回答「怎么做曝光」）

> **你的判断对：曝光是最难的一环。但它有成熟机制，不是靠「努力宣传」。**
> **本报告全部基于实测数据。**

## 一、⭐⭐ 先破一个误区：star 完全不能代表曝光

### npm 月下载量 vs GitHub star（实测）

| 插件 | star | **npm 月下载** | 下载/星比 |
|---|---|---|---|
| **dsh-free-search** | 547★ | **52,819** | **97×** |
| **dsh-mnemon** | 621★ | **51,615** | 83× |
| **dsh-univer-office** | 579★ | **48,113** | 83× |
| **modsearch** | 790★ | **45,722** | 58× |
| **dsh-genui** | 722★ | **38,329** | 53× |

| dsh-image-gen | 666★ | 26,845 | 40× |
| dsh-mobile | 557★ | 16,339 | 29× |
| dsh-vision-toolkit | 901★ | 12,780 | 14× |
| **dsh-ads（恶搞）** | **682★** | **仅 2,014** | **3×** ⚠️ |

### ⭐⭐ 三个颠覆性结论

| 结论 | 数据 |
|---|---|
| **① 真实用户是 star 的 30-97 倍** | 头部插件月下载 3-5 万，star 才 500-900 |
| **② 恶搞插件星高但没人装** | dsh-ads 682★ 但只有 2,014 下载 |
| **③ 实用插件的下载远超星数** | free-search 547★ 却 52,819 下载（97倍） |

**推论：不要追求 star，要追求「被真正装上」。star 是热闹，下载是钱。**

## 二、⭐⭐ 曝光的真实机制：榜单 + RSS

### 机制 1：所有市场站都按「安装量」排序

| 站点 | 排序维度（实测） | 显示安装量 |
|---|---|---|
| **dshmarket.com** | Install / downloads / top / Installs | ✅ |
| **dshmarketplace.dev** | Top / installs / 精选 | ✅ |
| **awesome-dsh-plugin.com** | Downloads / Newest / top | ✅ |
| **dshopen.org** | installs / downloads / top / **featured** | ✅ |

### 机制 2：四种榜单（决定你能不能被发现）

| 榜单 | 进入方式 | 对新插件友好度 |
|---|---|---|
| **Newest / 最新** | ✅ **发布即自动进入** | ⭐⭐⭐⭐⭐ **唯一免费入口** |
| **Top / 热门** | 靠**安装量**积累 | ⭐ 需要时间（但可爬） |
| **Featured / 精选** | 人工挑选 | ⭐⭐ 不可控 |
| **Trending / 飙升** | 短期增速 | ⭐⭐⭐ 有机会 |

### 机制 3：⭐⭐ RSS 自动流（最被忽视的曝光渠道）

**实测发现：`https://awesome-dsh-plugin.com/feed` 是活的 RSS**

| 项 | 数据 |
|---|---|
| HTTP 状态 | **200** |
| 格式 | 有效 XML（17KB） |
| 内容 | **每日新插件列表，含 owner/repo + 描述** |
| 样本 | `AsterionZephyr/dsh-desktop-hand … 2026-10-22 … Windows-only desktop control` |

**⚠️ 这很可能就是「插件日报」公众号的内容来源——他们订阅这个 RSS，每天整理发布。**

**对你的意义：发到索引里 → 自动进 RSS → 被日报作者看到 → 免费曝光。**

## 三、⭐⭐⭐ 曝光漏斗（完整路径）

```
① 写插件 + 发到 npm
   ↓
② 打 dsh-plugin 标签 + 提交到 9 个市场站
   ↓
③ 自动进「Newest」榜（各站）
   ↓
④ 自动进 awesome-dsh-plugin 的 RSS
   ↓
⑤ 插件日报作者订阅 RSS → 把你写进日报
   ↓
⑥ 用户看到 → 在 DSH 里 install
   ↓
⑦ npm 下载量上升 → 市场站排名上升 → 进 Top 榜
   ↓
⑧ 回到 ⑤，正向循环
```

**关键：②→④ 是全自动的（只要你提交了）。⑤ 之后靠内容传播。**

## 五、⭐⭐ 选题建议（基于下载数据）

| 该做什么 | 证据 |

| ✅ **搜索类**（3个都进Top，free-search 52,819下载） | DSH 最缺的能力 |
| ✅ **记忆类**（mnemon 51,615下载） | DSH 没有长期记忆 |

**规律：解决真实痛点 → 下载量高；博眼球 → star高但下载低。**

## 六、⭐⭐ 回答你的问题：「这条路可以做吗」

| 环节 | 数据结论 |
|---|---|
| **① 写插件** | ✅ 可行。头部插件代码量小（18-28 commits），文档齐全 |
| **② 曝光** | ✅ **有机制，不是靠运气**。Newest榜自动进 + RSS自动被日报抓 |
| **③ 挂广告** | ⚠️ **唯一未验证环节**。目录站卖广告位已验证，插件内挂广告无先例 |
| **④ 赚钱** | ⚠️ 生态内 0 个付费插件；但**真实用户量大（月下载3-5万）说明有商业价值** |

### 最有把握的路径（数据支持）

```
做一个「DSH 真实缺的功能」的插件（搜索/记忆/文档/状态）
   ↓ 解决真实痛点 → 下载量自然高（参考 free-search 5万+）
   ↓ 上 Newest 榜 + RSS → 被日报抓取 → 免费曝光
   ↓ 下载量推你上 Top 榜 → 更多曝光
   ↓ 有了几万用户 → 谈广告/赞助（那时你是流量主）
```

**关键认知：曝光 ≈ 自动机制 + 内容的可传播性。不是花钱买，是先做对东西。**
