# session 类 445 个插件细分拆解：哪个方向最赚钱

| 它解决什么 | 用户痛点 |

## 五、⭐ session 类为什么是「最好赛道」

| 理由 | 说明 |
|---|---|
| **所有用户都用** | 会话是 DSH 核心场景 |
| **高频** | 每次对话都涉及 |
| **痛点明确** | 上下文爆、找不到历史、会话太多乱 |
| **平均下载最高** | 5,439（仅次于 market 的 7,707） |
| **持续需求** | 用户越多，会话越多，越需要管理 |

## 六、⭐⭐ 但要注意的现实

| 事实 | 说明 |
|---|---|
| **billion-context 一家独大** | 177 万下载，占 session 类 73% |
| **第二名只有 16 万** | 差 11 倍 |
| **大部分插件下载很低** | 445 个里只有少数过万 |
| **做上下文压缩很难赢** | 需要极强技术 + 已被占 |

**→ 做 session 类要避开上下文压缩，选搜索/管理/模板这类。**
