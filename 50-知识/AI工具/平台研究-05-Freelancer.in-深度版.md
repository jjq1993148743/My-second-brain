# 二、与 freelancer.com 的关系

**这是同一个平台的印度镜像站。**

| 项 | freelancer.com | freelancer.in |
|---|---|---|
| 域名 | .com | .in |
| 计价 | USD/GBP/EUR | **INR（卢比）** |
| 用户群 | 全球 | **印度为主** |
| 页面结构 | 完全相同 | 完全相同 |
| 抽成规则 | 相同 | 相同 |
| 中位投标 | 41 | **44** |
| 中位预算 | $147 | 约 $168 |

**结论：本质是同一个平台，只是本地化了货币和用户群。研究其中一个就等于研究两个。**

# 三、印度市场的特点

## 优势

| 点 | 说明 |
|---|---|
| **单价不低** | 中位 $168，略高于全球站 |
| **本地需求** | 印度本土企业需求（如本地化服务） |
| **英语环境** | 沟通无障碍 |

## 劣势

| 点 | 说明 |
|---|---|
| **竞争最激烈** | 平均 74 人抢，最高 465 人 |
| **低价竞争者多** | 印度本地开发者成本低，压价严重 |
| **同样的平台问题** | 抽成高、dispute 不透明、隐藏费用 |

# 六、数据与复现

| 文件 | 内容 |
|---|---|
| `_flin_projects.json` | 630 条（标题/预算/投标数） |
| `_raw_flin/p01-p10.html` | 10 页原始 HTML |
| `parse-flin.mjs` | 解析器（复用 freelancer.com 逻辑，改币种） |

**抓取纪律**：curl 串行 10 页，每页间隔 2.5–4.5 秒。

**技术要点**：与 freelancer.com 完全同构，只是货币符号从 `$` 变为 `₹`。

> **局限说明**：标题字段 25% 抓取到描述首句，与全球站同样的问题（HTML 结构导致）。
