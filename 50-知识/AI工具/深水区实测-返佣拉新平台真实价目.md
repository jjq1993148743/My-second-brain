# 深水区实测 · 返佣/拉新平台的真实价目

> **验证目标：补贴地图里的 A 类（企业获客预算）到底真不真、多少钱。**
> **验证方式：任务墙实测（26 个）+ 搜狗微信定向搜索。**
> **结果：任务墙网站 18/26 打不开（全是 App 生态），但搜狗微信挖出了真实平台名和价目。**

## 一、⭐⭐ 核心发现：这类信息在「公众号」里，不在「网站」上

| 渠道类型 | 实测结果 | 说明 |
|---|---|---|
| 任务墙网站（趣闲赚/赏帮赚等） | ❌ 18/26 打不开 | **全是 App 生态，官网只做下载引导** |
| 什么值得买 | ✅ 126 个价格信号 | 羊毛线报聚合，真实 |
| 站长之家 | ✅ 价格信号（1000-5999元） | 是**网站交易价**，不是返佣，误命中 |
| **搜狗微信定向搜索** | ✅ **挖出真实平台名+价目** | **这才是 L3 信息的正确入口** |

**结论：返佣/拉新这类 L3 信息，主力载体是公众号，不是网站。**

**但这不影响逻辑——它的价值不在单价，在「可规模化 + 无门槛」。**

## 四、⭐⭐ 这类生意的真实结构（实测后理解更深了）

```
广告主（银行/运营商/App）
    ↓ 付推广费
CPA 联盟/返佣平台（卡盒/爆推联盟等）
    ↓ 分发任务+抽成
地推团队/个人推广者 ← 你在这里
    ↓ 拉来真实用户
终端用户（办卡/下载/注册）
```

| 关键认知 | 说明 |
|---|---|
| **平台靠抽成赚钱** | 广告主给 ¥30，到你手里可能 ¥10-18 |
| **可以做下级** | 拉人做地推还能拿间推奖励（3-18%） |
| **门槛极低** | 不需要技能，不需要本金，注册就能接 |
| **规模化才是钱** | 单人 ¥10-58，要做量 |

## 五、⚠️ 红线（实测中发现了大量灰产）

| 灰产信号 | 实测看到 |
|---|---|
| **批量办卡骗返现** | 哈尔滨案例：骗取 500+ 条个人信息、开出 150+ 张卡 → **公安介入** |
| **卖卡/卖号** | 多篇普法文：《卖银行卡、手机卡，会坐牢?》 |
| **刷单返现** | 「刷单返现诱惑多，坑钱骗你没商量」 |

**合规边界：自己真实办卡/真实推广+带来真实用户；绝不批量、绝不买卖账号。**
