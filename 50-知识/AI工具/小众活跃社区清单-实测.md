# 真正小众但活跃的社区清单（实测数据）

> **你要的是「比 YouTube 小、但里面东西够新鲜」的平台。**
> **这轮我抓了两个数据源的真实数据：GuildRegister（22 品类）和 AllChans（imageboard 点击排行）。**

---

## 一、先纠正一个前提

| 你的判断 | 实际 |
|---|---|
| 「Reddit 大部分人不知道」 | ❌ **1.303 亿日活**（2026 Q2，demandsage 统计），全球前十大网站 |
| 「小众 = 有机会」 | ✅ 方向对，但**要再低两个数量级** |

**真正的小众是：几千到几万人、在线率高、中文圈几乎没人搬过。**

## 三、⭐ 数据源 2：Imageboard（AllChans 点击排行）

**这是最「小众」的一层：匿名图片论坛，无账号、无算法、无推荐。**

| 站点 | 出站点击数 |
|---|---|
| **8chan.moe** | **11,316** |
| **7chan.org** | **7,319** |
| 8kun.top | 5,391 |
| 22chan.org | 3,636 |
| 4chon.me | 3,179 |
| 1chan.us | 2,969 |
| 4fuck.org | 2,685 |
| 4-ch.net | 2,658 |
| 4chan.org（本体） | 2,371 |

**数据说明**：基于 AllChans 站点的出站点击统计（[来源](https://allchans.org/2025/04/24/top-imageboards/)），原文注明「不 100% 准确，因为很多人用追踪拦截、大站有直接流量」。

### ⚠️ 这一层要谨慎

| 风险 | 说明 |
|---|---|
| 内容不可控 | 匿名版什么都有，不适合做宠物科普素材源 |
| 反商业 | 发广告直接被骂 |
| 语言/文化 | 英文为主，亚文化浓 |

**→ 建议当「观察窗」而不是「发布渠道」：看他们在聊什么、用什么梗，回来做内容。**

## 四、⭐⭐ 还有哪些方向（我还没挖的）

| 方向 | 说明 | 状态 |
|---|---|---|
| **老式论坛（phpBB / Discourse）** | 兴趣论坛，比如养猫论坛、园艺论坛 | ⬜ 未挖 |
| **Substack / Ghost 独立博客** | 个人深度内容，评论区活跃 | ⬜ 未挖 |
| **Mastodon / Fediverse 实例** | 去中心化，小实例极活跃 | ⬜ 未挖 |
| **Hacker News / Lobsters** | 技术圈，评论质量极高 | ⬜ 未挖 |
| **Are.na** | 灵感收藏社区，设计师/写作者聚集 | ⬜ 未挖 |
| **Cohost**（如果还在运营） | 反算法社媒 | ⬜ 未挖 |
| **地区性平台** | 比如台湾的 Dcard、日本的 5ch、韩国的 Naver Cafe | ⬜ 未挖 |

## 五、⭐⭐⭐ 对你「找新鲜内容」的实际建议

| 目的 | 该去哪 |
|---|---|
| **找选题灵感**（别人在问什么） | Reddit 细分 sub + Discord 活跃群 |
| **找没被搬过的内容** | **Imageboard + 老式论坛**（中文圈几乎不碰） |
| **找可引用的数据** | GuildRegister（社区规模）、AllChans（点击排行） |
| **找图** | Unsplash / Pexels（不是社交平台） |

### ⭐ 一条更实际的判断

> **「小众」不等于「有价值」。**
> **真正的价值是「小众 + 高活跃率 + 中文圈不知道」。**

**按这三个条件筛，22 个品类里符合的是：**

| 品类 | 社区 | 为什么 |
|---|---|---|
| **Art** | Rattiest Gang（25.1%） | 3.4 万人，25% 在线，中文圈完全不知道 |
| **Hobby** | クトゥルフ神話TRPG（23.0%） | 日本 TRPG 圈，1 万人高活跃 |
| **Writing** | Dungeon Scrawlers（21.6%） | 916 人但 21.6% 活跃，小而精 |
