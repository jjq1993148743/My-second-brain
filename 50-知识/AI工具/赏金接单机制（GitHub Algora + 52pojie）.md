# 赏金接单机制（GitHub Algora / 52pojie / AI 比赛）

> 2026-10-16 ｜ 用途：**不需要获客**的变现路径——需求方主动挂赏金，你解题拿钱。
> 这是所有方向里唯一"不用找客户"的一类。

## 一、GitHub Algora（最推荐给开发者）

| 项目 | 数据 |
|---|---|
| 收益参考 | V2EX 网友：**碎片时间一年多赚 1w 多**，"花的时间不多" |
| 平台 | **algora.io** |
| 查询方式 | GitHub API：`is:open label:"💎 Bounty"` |
| **当前规模（2026-10-16 实测）** | **561 个 open issue** |

### 实测样例

| 仓库 | 金额 | 任务 |
|---|---|---|
| `UnsafeLabs/RFC-5322#1` | **$400** | 实现 ABNF 合规的 email 地址解析器（完整覆盖 §3.2–§4.4） |
| `oll4com/spaceapp` | **$150 × 6 个** | 部署脚本/按服务容器镜像/rootless Podman/WebGL 渲染 5 万节点/OTLP trace/CI 测试 |
| `ClankerNation/OpenAgents` | $9k / $8k / $3k / $2k | SDK 编解码修复、API 结构化错误响应、限流区分认证 |

> 注意：`spaceapp` 那 6 个是**同一天创建**的，说明有团队在批量挂赏金——**这类仓库值得订阅**。

### 四条实战技巧（V2EX 原帖）

1. **只接你能完美解决的**——不要试水
2. **已有 Assignee 就放弃**——避免浪费时间
3. **让发布者分配给你**——否则可能白干
4. **收款只能用 Stripe**（有门槛）

## 四、三类赏金对比

| 维度 | GitHub Algora | 52pojie 悬赏 | AI 比赛 |
|---|---|---|---|
| 单价 | **$150–$9000+** | 25–201 CB（约几元–几十元） | 奖金/资源，不确定 |
| 技术门槛 | 高（要真能改开源项目） | 低（多为代下载/转换） | 中 |

| 收款 | Stripe（有门槛） | 论坛币（变现麻烦） | 看主办方 |

## 五、配套：V2EX 副业节点情报脚本（已建）

脚本位置：`50-知识/AI工具/_scripts/v2ex-sidehustle.mjs`

**用法**：
```bash
node v2ex-sidehustle.mjs          # 输出最新 25 条，自动提取金额和周期
node v2ex-sidehustle.mjs 月入      # 只输出命中关键词的
```

**原理**：V2EX 提供 JSON Feed（`https://www.v2ex.com/feed/sidehustle.json`），一次请求拿 50 条**带正文**的复盘，不需要注册。脚本自动用正则提取金额（万/千/k/w/元/刀/\$/¥）和时间周期（小时/天/月/年）。

> AI 推测：这个 Feed 是整个调研里性价比最高的入口。建议做成每日定时任务，输出推送到飞书/微信。

**注意**：本机需要代理（`127.0.0.1:7897`），脚本里已写死；如果换网络环境要改 `PROXY` 常量。
