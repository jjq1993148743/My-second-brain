# DSH 生态的付费意愿：实测数据告诉你真相

> **223 个插件提到「付费」，但拆开看——没有一个是真付费插件。**
> **这轮回答一个问题：这个生态里，钱到底在哪？**

## 一、⭐⭐⭐ 223 个「付费」插件的真相

### 搜索结果

| 关键词 | 命中插件数 |
|---|---|
| 付费 / 收费 / 订阅 / 价格 / premium / paid / subscription | **223 个** |

### ⭐ 但拆开看，全是「显示订阅额度」

| 排名 | 插件 | 下载 | 它说的「付费」是什么 |
|---|---|---|---|
| 1 | whale-widget | 199,295 | **显示**余额和每轮消耗 |
| 2 | dsh-cost-meter | 106,366 | **统计** API 费用 |
| 3 | dsh-free-search | 51,336 | 免费引擎 + **付费引擎**（Exa/Perplexity） |
| 4 | dsh-codex-subscription | 24,793 | **用** ChatGPT 订阅 |
| 5 | dsh-ui-usage-billing | 15,296 | **显示**计费仪表盘 |
| 6 | dsh-subscriptions | 12,431 | **接入** ChatGPT/Claude 订阅 |
| 7 | dsh-plugin-subscriptions | 10,442 | **接入**订阅当 LLM 提供方 |
| 8 | dsh-opencode-go | 8,289 | **接入** OpenCode 订阅 |

### ⭐⭐⭐ 结论

> **223 个里，0 个是「卖插件」的。全部是「帮你管理/显示/接入别人家的付费服务」。**

**这解释了为什么 `commercialCount = 0`（没有任何插件 homepage 指向商业站点）。**

## 三、⭐⭐⭐ 三个残酷的事实

### 事实 1：付费插件数量 = 0

| 证据 | 数据 |
|---|---|
| 223 个「付费」插件 | **全部是「管理别人付费」** |
| commercialCount | **0**（没有指向商业站点） |
| 有 homepage 的 44 个 | 都是文档站/个人站/开源项目 |

### 事实 2：用户愿意为「省钱」买单，但不愿为「插件」买单

| 现象 | 数据 |
|---|---|
| **余额/费用类插件下载极高** | whale-widget 19.9万、cost-meter 10.6万 |
| **但它们本身免费** | 没人给它们付钱 |
| **用户在省钱上很敏感** | 所以这些插件火 |

**→ 用户在意「花了多少钱」，但不愿意为「帮我省钱」付费。**

### 事实 3：真正赚钱的是「订阅接入」类

| 插件 | 下载 | 它做什么 |
|---|---|---|
| dsh-codex-subscription | 24,793 | 用 ChatGPT 订阅当模型 |
| dsh-subscriptions | 12,431 | 接入 4 家订阅 |
| dsh-plugin-subscriptions | 10,442 | 接入订阅当 LLM |
| dsh-opencode-go | 8,289 | 接入 OpenCode |
| dsh-agy-link | 5,445 | 接入 Antigravity |

**→ 这些插件的价值是「帮用户用已有的订阅」，不是「卖新东西」。**

## 四、⭐⭐ 那钱在哪？（三个可能）

| 可能 | 依据 | 判断 |
|---|---|---|
| **① 卖「接入别人订阅」的服务** | 订阅接入类下载都过万 | 🟡 但插件本身免费 |
| **② 做「省钱工具」引流** | 余额类下载 19.9 万 | ✅ **已验证有流量** |
| **③ 做「企业定制」** | 生态里没人做 | 🟡 空白但未验证 |

### ⭐⭐⭐ 一个被忽略的洞察

> **用户最在意的是「API 花了多少钱」。**
> **前 2 名 usage 插件（dsh-context 15.6万 + cost-meter 10.6万）= 26 万下载，都在做这件事。**
> **而 billion-context（177 万下载）做的是「省 token」= 省钱。**

**→ 「省钱」是这个生态最强的需求。**

## 五、⭐⭐⭐ 对你的启示

### 如果你想做插件赚钱

| 路径 | 可行性 | 依据 |
|---|---|---|
| **直接卖插件** | ❌ **0 个成功案例** | 223 个「付费」插件全是免费 |
| **做省钱工具引流** | ✅ **已验证有流量** | whale-widget 19.9 万、cost-meter 10.6 万 |
| **做订阅接入引流** | ✅ 有流量 | 订阅类 8k-2.4万 |
| **做企业定制** | 🟡 空白 | 但没人验证 |
| **导流到私域再变现** | ✅ 唯一验证过的 | brewreel 模式 |

### ⭐ 最稳的路径（数据支持）

```
做一个「帮用户省钱」的插件（余额/费用/token 优化）
   ↓ 这个生态最认这个（billion-context 177万、whale-widget 19.9万）
   ↓ 下载量上来后
   ↓ 导流到你的公众号/站
   ↓ 在私域卖服务（不是卖插件）
```

## 六、⭐⭐ 一个反直觉的发现

### 我们的 6 个职业插件，可能不如「省钱类」好卖

| 类型 | 代表 | 下载 |
|---|---|---|
| **省钱类** | billion-context | **1,772,945** |
| | whale-widget | 199,295 |
| | cost-meter | 106,366 |
| **职业类** | dsh-expert（636 专家） | 451 |
| | dsh-network-engineer | 355 |

**→ 差 4,000 倍。**

### ⭐ 为什么

| 原因 | 说明 |
|---|---|
| **省钱是所有人的痛点** | 每个用户都在花 API 钱 |
| **职业是部分人的痛点** | 只有销售/HR/律师在意 |
| **省钱可量化** | 「省了 5 倍 token」看得见 |
| **职业价值难量化** | 「话术好不好」没法立刻验证 |

## 七、⭐⭐⭐ 修正后的建议

| 优先级 | 做什么 | 依据 |

| **峰谷价提醒** | DeepSeek 有峰谷价，错峰省一半 |
