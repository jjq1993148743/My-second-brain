## 三、⭐⭐⭐ 这个插件有什么（内容清单）

### 开场（4 种场景）

| 场景 | 要点 |
|---|---|
| 电话开场 | 30 秒法则、避免 3 个错误 |
| 微信开场 | 首条消息 4 行以内 |
| 拜访开场 | 破冰三要素 |
| 转介绍 | 借介绍人信用 |

### 需求挖掘（SPIN 完整）

| 环节 | 作用 |
|---|---|
| **S**ituation 背景 | 建立事实基础 |
| **P**roblem 难点 | 引导说出不满 |
| **I**mplication 暗示 | **放大后果（最关键）** |
| **N**eed-payoff 回报 | 让客户自己说值 |

### 异议处理（20+ 场景，这是最值钱的）

| 类别 | 场景 |
|---|---|
| **价格** | 太贵了 / 预算不够 / 能不能便宜点 |
| **时机** | 再考虑 / 现在不急 / 内部讨论 |
| **信任** | 没听过你们 / 能保证效果吗 / 已有供应商 |
| **竞争** | XX 更便宜 / XX 功能更多 |
| **决策** | 要问领导 / 先试用 |
| **其他** | 发资料看看 / 行业特殊 / 太忙了 |

### 成交（6 种方法）

假设成交 · 二选一 · 限时优惠 · 分阶段 · 痛点回顾 · **沉默成交**

**另附「成交信号识别」：客户出现 5 种信号就该成交了。**

### 跟进（含节奏表）

| 阶段 | 时间 | 动作 |
|---|---|---|
| 首次 | 24 小时内 | 发纪要 + 补充材料 |
| 二次 | 3-5 天 | 发案例/数据 |
| 三次 | 1-2 周 | 问决策进展 |
| 长期 | 每月 | 发行业信息（不提成交） |

## 四、⭐⭐ 5 个行业的定制内容

| 行业 | 专属痛点 | 定制话术 |
|---|---|---|
| **SaaS** | 数据迁移、员工不愿用、合规 | 迁移方案、试点策略、安全白皮书 |
| **制造业** | 停产风险、工人年龄大、老设备 | 试点不影响产线、扫码即用、采集模块 |
| **保险** | 合规、代理人流动、客户跟进 | 话术审核、标准化培训、自动提醒 |
| **教育** | 家长不信任、试听转化、退费 | 免费试听、学习诊断报告、合同退费 |
| **房产** | 观望、带看不成交、政策变化 | 成交数据、需求聚焦、政策解读 |
