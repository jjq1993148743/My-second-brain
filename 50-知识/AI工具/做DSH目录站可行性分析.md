# 做 DSH 目录站：完整可行性分析

> **数据指向的最赚钱路径。这轮拆开看：技术门槛、成本、数据源、竞争、收入。**
> **结论：技术门槛极低（全免费托管），数据源公开，但竞争已经 10+ 家。**

## 一、⭐⭐⭐ 现有目录站的技术栈（实测）

| 站点 | 托管 | 成本 |
|---|---|---|
| **dshplugin.store** | **Vercel** | **免费/低价** |
| **awesome-dsh-plugin.com** | **GitHub Pages** | **完全免费** |
| dshopen.org | Cloudflare | 免费 |
| dshmarketplace.dev | Cloudflare | 免费 |
| deepseek.stream | Cloudflare | 免费 |

### ⭐⭐⭐ 关键发现

> **所有目录站都用免费/低价托管！**
> **GitHub Pages 完全免费，Vercel 和 Cloudflare 免费额度够用。**

**→ 做目录站的服务器成本 = 0 元。**

## 二、⭐⭐⭐ 数据从哪来（实测）

### awesome 的数据源

```json
{
  "name": "awesome-dsh-plugin",
  "source": "https://github.com/awesome-dsh-plugin/awesome-dsh-plugin",
  "updated": "2026-10-22"
}
```

### ⭐⭐ 这说明

| 事实 | 说明 |
|---|---|
| **数据源是 GitHub 仓库** | 它自己维护一个仓库，存插件数据 |
| **每天更新** | `updated: 2026-10-22` |
| **格式是 JSON** | `plugins.json` 7.2MB |

### ⭐⭐⭐ 数据从哪抓

| 来源 | 怎么抓 |
|---|---|
| **GitHub topic:dsh-plugin** | 21,513 个仓库，用 API 抓 |
| **npm registry** | 搜 dsh-plugin 关键词 |
| **各站已有的 JSON** | awesome 的 plugins.json、dshopen 的 index.json |

**→ 数据源完全公开，谁都能抓。**

## 六、⭐⭐⭐ 新进入者的机会在哪

### 机会 1：做「垂直目录」（不是全量）

| 现状 | 机会 |
|---|---|
| 所有站都在做「全量收录」 | **没人做「精选/评测」** |
| 32,428 个插件用户看不完 | **帮用户筛选有价值** |

### 机会 2：做「真实数据」（打假）

| 现状 | 机会 |
|---|---|
| 各站插件数差 28 倍 | **做「真实插件数」核查** |
| 有的站数据明显虚高 | **做「下载量真实性」对比** |

### 机会 3：做「垂直场景」目录

| 场景 | 说明 |
|---|---|
| **省钱类插件目录** | 我们已经有 cost-advisor，可以延伸 |
| **职业插件目录** | 我们已经有 6 个职业插件 |
| **中文插件目录** | 中文插件散落在各站 |

### ⭐⭐⭐ 机会 4：做「数据服务」而不是「目录」

| 做什么 | 卖给谁 |
|---|---|
| **插件数据 API** | 给其他目录站用 |
| **趋势报告** | 给插件作者看（哪些类别在涨） |
| **竞品监控** | 给插件作者看（同类插件动态） |

## 七、⭐⭐ 我的判断（基于数据）

| 路径 | 可行性 | 理由 |
|---|---|---|
| **做全量目录站** | ❌ **不建议** | 头部已 3 万页，你从 0 开始打不过 |
| **做垂直精选目录** | ✅ **可做** | 没人做「筛选」，用户需要 |
| **做数据服务** | ✅ **可做** | 已有 JSON 索引，加工即可 |
| **做中文插件目录** | ✅ 可做 | 中文插件散落 |
| **做插件评测/打假** | ✅ **推荐** | 零成本内容型 |

### ⭐⭐ 最优路径

```
不做「第 11 个全量目录站」
   ↓
做「DSH 插件真实数据 + 精选」
   ↓ 用我们已有的 6,378 插件全量数据（含 stars/downloads/added）
   ↓ 做别人没做的：真实下载榜、增速榜、类别机会榜
   ↓ 内容型 SEO（每周发一篇榜单）
   ↓ 流量 → 卖广告位 / 卖数据服务
```
