# 平台研究 · 最终行动计划（可执行版）

> **这份不是研究报告，是行动清单。**
> 前面 20+ 份报告的所有分析，浓缩成「你明天该做什么」。

## 一、核心结论（一句话）

> **同样会写代码，投简历进公司比在接单平台投标，收入高 10-50 倍。**

| 渠道 | 年化收入 | 时薪 |
|---|---|---|
| React/Go 远程职位 | **$242,000 – $385,000** | **$121 – $192** |
| Laravel 远程职位 | $160,000 – $220,000 | $80 – $110 |
| WWR 远程职位（中位） | $60,000 | $30 |
| Freelancer.com 接单 | $22,000 | **$11** |
| **一品威客接单** | **$5,300** | **$2.65** |

**但接单的低门槛是真实的——注册即可开始，入职要面试和英语。**

## 二、⭐ 三条路，选一条

### 路线 A：投远程职位（收入最高）

**如果满足任一条件：**
- 英语能面试
- 会 React / Go / Android / .NET / Laravel / Vue 中任一个
- 能接受 1-3 个月的求职周期

**去这些平台：**

| 平台 | 技术栈 | 薪资透明度 | URL |
|---|---|---|---|
| **reactjobs.io** | React | ✅ 公开（$125k–385k） | 直接搜 |
| **golangprojects.com** | Go | ✅ 公开（$120k–352k） | 直接搜 |
| **androidjobs.io** | Android | ✅ 公开（$96k–225k） | 直接搜 |
| **dotnetjobs.com** | .NET | ✅ 公开（$67k–196k） | 直接搜 |
| **vuejobs.com** | Vue | ✅ 公开（$82k–167k） | 直接搜 |
| **larajobs.com** | Laravel | ✅ 公开（$48k–220k） | 直接搜 |

**第一步动作：**
1. 打开对应你技术栈的招聘板
2. 看 10 个职位的 JD 和薪资
3. 挑 3 个薪资合适的，改简历投递

### 路线 B：接单（门槛最低）

**如果：英语/技术还不够面试，但想先有收入。**

**优先级：**

| 顺序 | 平台 | 为什么 | 中位投标 | 中位预算 |
|---|---|---|---|---|
| **1** | **Useme** | **不要公司主体** | 18 | €650 |
| **2** | **一品威客** | 竞争最小 + 中文 | **1** | ¥3,200 |
| 3 | PeoplePerHour | 只作情报源 | 20 | $99 |
| ❌ | Codeur.com | 49 人抢，别碰 | 49 | <€500 |
| ❌ | 猪八戒 | 全是僵尸项目 | — | — |

**第一步动作：**
1. **注册 Useme**（useme.com），验证三件事：
   - 中国个人能否注册
   - 抽成多少
   - 提现方式
2. 如果 Useme 不行，**注册一品威客**（epwk.com）
3. 挑 3 个投标 ≤5 的项目试投

### 路线 C：会小语种（隐藏机会）

**如果会俄语/德语/法语：**

| 语言 | 平台 | 优势 | 门槛 |
|---|---|---|---|
| **俄语** | **FL.ru** | **630 条 + 6 小时新鲜度 + 238 条职位** | 需 PRO 账号 |
| **德语** | **Freelancermap** | **511 条 + 42% 全远程** | 需德国税号 |
| **法语** | **Collective** | **TJM €654/天（约 ¥5,000/天）** | 需欧盟身份 |

**这三个平台的数据质量是所有研究里最高的，但门槛也最高。**

## 六、如果三条路都不想走

**那说明现在的问题不是「缺平台」，是「缺技能」或「缺时间」。**

| 问题 | 解法 |
|---|---|
| 技能不够面试 | 先用接单平台练手（Useme），同时学一个高薪技术栈（React/Go） |
| 没时间 | 接单平台的小项目更好控制时间（一品威客中位 ¥3,200，几天能做完） |
| 英语不行 | 先做中文（一品威客）+ 用翻译工具辅助英文（Useme 英语界面不复杂） |

## 七、研究的边界（诚实说明）

### 做了什么

| 项 | 数量 |
|---|---|
| 深度报告 | **24 份** |
| 真实数据 | **6,534 条** |
| 尝试平台 | **130+** |
| 成功抓取 | **19 个** |
| 达到 200+ 条 | **10 个** |

### 没做到什么

**「50 个平台」没做到。** 原因：

| 障碍 | 数量 | 例子 |
|---|---|---|
| SPA 深度渲染 | 30+ | Workana、Sribu、Kwork、猪八戒主站 |
| 强制登录 | 10+ | Upwork、CrowdWorks、Lancers、Coconala |
| 无项目列表 | 10+ | Fiverr、Patreon、99designs、实现网 |
| 同系统多语言 | 8 域名 | Freelancer 占 8 个、Freelancermap 占 3 个 |
| 赏金全封闭 | 14 | HackerOne、Bugcrowd、Algora |
| 垂直板停运 | 21 | 27 个技术栈板只有 6 个活着 |

**这是公开可抓数据的极限，不是执行问题。**
