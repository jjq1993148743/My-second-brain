# 【总结】DSH 插件赚钱项目 · 完整总结

> **一句话：研究完了，7 个插件已做好并验证，等着发布。**

## 一、起点：你的想法

> 「我要写插件或 skills → 然后推广 → 然后挂广告 → 然后赚钱」

> 「我认为这里最难的是曝光」

**你的判断是对的。曝光确实是这条路上最难的一环。**

**但我研究下来发现：比曝光更根本的问题是——选什么方向做。**

---

## 二、⭐ 最重要的三个结论

### 结论 1：技术方向全部红海

| 方向 | 竞品数 | 最高下载 |
|---|---|---|
| PDF 处理 | **151** | 92,083 |
| 视觉理解 | 134 | 95,397 |
| 模型接入 | 349 | 24,793 |
| 浏览器自动化 | 139 | 51,336 |
| 登录态管理 | 77 | 7,024 |

**→ 这些方向都有人做，而且做得很大。新进入者打不过。**

### 结论 2：职业方向全部空白

| 方向 | 真实竞品数 | 最高下载 |
|---|---|---|
| **销售** | **0** | **0** |
| HR | 2 | 893 |
| 律师 | 2 | 1,179 |
| 运营 | 2-3 | 1,234 |
| 财务 | 3-5 | 1,320 |
| 教师 | 5 | 1,302 |

**→ 技术人不懂职业场景，所以没人做。这是你的机会。**

### 结论 3：职业工具「下限高、上限低」

| 指标 | 职业工具 | 技术工具 |
|---|---|---|
| 插件数 | **70** | 810 |
| **下载中位数** | **701** | **218** |
| 过千占比 | **43%** | 33% |
| 天花板 | **约 1,320** | 208,637 |

**→ 职业工具「更容易有人用」，但「不可能爆」到 10 万。**

## 三、⭐ 曝光：答案是「三个自动机制」

### 不需要求人，做好准备就会被抓

| 机制 | 证据 | 你要做什么 |
|---|---|---|
| **① 打 GitHub topic 自动收录** | dshmarketplace.dev 原文：「gets you listed on the next sync, **with no submission needed**」 | `gh repo edit --add-topic dsh-plugin` |
| **② 发 npm 才进 Plugin Hub** | dsh-plugin.org 原文：「**only lists plugins published to NPM**」 | `npm publish` |
| **③ 日报扫描 GitHub 新增仓库** | 4 家日报日更，**连 ★0 都写** | README 第一句写清价值 |

### 三个反直觉事实

| # | 事实 | 数据 |
|---|---|---|
| 1 | **star 完全不代表曝光** | dsh-free-search：547★ 但月下载 **52,819** |
| 2 | **曝光 ≠ 你的流量** | 849 个插件里 44 个（5.2%）挂了外部网站做导流 |
| 3 | **别指望蹭母项目** | archify-dsh 87,067★ 是母项目的星，不是插件的 |

### SEO 是主战场（sitemap 实测）

| 站点 | sitemap 条目 | 判断 |
|---|---|---|
| **dshplugin.store** | **32,449** | 🥇 SEO 最大 |
| **awesome-dsh-plugin.com** | **12,806** | 🥈 有中文版 + RSS |
| deepseek.stream | 584 | 🥉 |
| dshmarketplace.dev | 248 | 小 |
| dsh-plugin.org | 3 | 不靠 SEO |
| dshopen.org | 2 | JSON 数据层 |
