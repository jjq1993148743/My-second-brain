# 平台研究 #35 · 一品威客：列表页 vs 详情页交叉验证【99 + 259 条】

> **这是方法论上最重要的一份：证明「只看列表页会被系统性误导」。**
> **同一平台，列表页中位预算 ¥3,200，详情页中位预算 ¥998 —— 差 3.2 倍。**

## 一、⭐ 核心发现：两个数据源系统性不一致

| 指标 | 列表页（259 条） | 详情页（99 条） | 差异 |
|---|---|---|---|
| **中位预算** | **¥3,200** | **¥998** | **3.2 倍** |
| 最高预算 | ¥48,000 | **¥200,000** | 4.2 倍 |
| 有预算比例 | 51% | **97%** | 1.9 倍 |

## 二、预算分布对比（关键表）

| 预算区间 | 列表页 | 详情页 |
|---|---|---|
| **< ¥500** | **0** | **37（37%）** |
| ¥500–2k | 43 | 24 |
| ¥2k–10k | 61 | 23 |
| ¥10k–50k | 28 | 9 |
| **¥50k+** | **0** | **3（3%）** |

### 这个对比说明什么

**列表页完全没有 <¥500 的项目，也没有 >¥50k 的项目。**

**详情页有 37 个 <¥500，也有 3 个 >¥50k。**

## 三、⭐ 为什么会有这种偏差

| 原因 | 解释 |
|---|---|
| **列表页排序** | 默认按「热门/推荐」排序，过滤掉低价和小众项目 |
| **列表页截断** | 只显示 9 页，后面的项目不在列表里 |
| **列表页字段缺失** | 只有 51% 有预算，其余为空（未参与统计） |
| **详情页全量** | 直接按 ID 抓取，覆盖真实分布 |

**结论：列表页是「精选视图」，详情页是「全量视图」。**

## 四、⭐ 详情页独有信息：截稿时间

| 指标 | 数值 |
|---|---|
| 有截稿时间 | 97 条 |
| **未来截稿（≥2026-10-20）** | **87 条（90%）** |
| 已过期 | 10 条（10%） |

**90% 的项目截稿时间在未来 → 平台真实活跃。**

**10% 已过期 → 说明有少量历史任务残留（正常）。**

## 五、⭐⭐ 修正后的真实结论

### 关于预算

| 之前认为 | **实际** |
|---|---|
| 中位预算 ¥3,200 | **中位 ¥998**（列表页高估 3.2 倍） |
| 最高 ¥48,000 | **最高 ¥200,000**（列表页低估 4.2 倍） |
| 没有低于 ¥500 的项目 | **37% 低于 ¥500** |

**两个方向都错了：既高估了中位数，又低估了天花板。**

### 关于每竞争者收益

**之前算的 ¥2,500（= ¥3,200 预算 ÷ 1 人）是基于列表页数据。**

**如果用详情页中位 ¥998 ÷ 1 人 = ¥998。**

| 数据源 | 中位预算 | 中位投标 | 每竞争者收益 |
|---|---|---|---|
| 列表页 | ¥3,200 | 1 | ¥2,500 |
| **详情页** | **¥998** | 1 | **¥998** |
| 差异 | | | **2.5 倍** |

**⚠️ 修正：一品威客的每竞争者收益应该是 ¥998，不是 ¥2,500。**

**但即使 ¥998，仍是 Useme（$30.3 ≈ ¥218）的 4.6 倍。**

## 六、方法论教训（最重要）

### 教训 1：列表页有系统性偏差

| 偏差类型 | 表现 |
|---|---|
| **低价项目被过滤** | 列表页 0 个 <¥500，详情页 37 个 |
| **高价项目不显示** | 列表页最高 ¥48k，详情页 ¥200k |
| **中间值被放大** | 中位数高估 3.2 倍 |

### 教训 2：必须用详情页验证列表页

```
正确流程：
  1. 列表页收集 ID（快速）
  2. 详情页抓全量数据（准确）
  3. 对比两者，找出偏差
  4. 只用详情页数据做决策
```

### 教训 3：字段缺失率是警报

| 平台 | 列表页字段完整率 | 判断 |
|---|---|---|
| 一品威客 | 51%（预算） | ⚠️ 有偏差 |
| Useme | 32%（预算） | ⚠️ 有偏差 |
| Codeur | 54%（预算） | ⚠️ 有偏差 |
| **PPH** | **97%（预算）** | ✅ 可信 |
| **Freelancermap** | **96%（日期）** | ✅ 可信 |

**字段完整率低于 60% 的平台，列表页数据都可能失真。**
