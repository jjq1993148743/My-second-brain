# 四、抽成结构（Wise 官方博文核实）

| 与同一客户累计成交额 | 抽成 |
|---|---|
| **£250 以下** | **20%** |
| £250 – £5,000 | 7.5% |

**但**：托管余额不足时平台明说**"不保证追回"**

# 六、这个平台对我赚钱计划的作用

## ✅ 有价值的用途

| 场景 | 说明 | 建议频率 |
|---|---|---|
| **免费市场情报** | 免登录看真实预算/竞争度 | 每周一次 |
| **接小单练手** | £50–150、提案<10 的单 | 前 3 单 |
| **抢零提案单** | 1.7% 概率，但抢到就是你的 | 每天扫 |
| **长期客户降成本** | 20% → 7.5% → 3.5% | 维护 2–3 个老客 |

## ❌ 不能指望的

| 场景 | 原因 |
|---|---|
| 赚大钱 | 中位 $90；$3,500 的活 49 人抢 |
| 稳定收入 | 1.3 分口碑 + chargeback 不兜底 |
| 高效获客 | 平均 28 个竞争者 |
| 靠新客户积累 | **37% 客户是新号，93% 未验证** |

## 🔴 必须防的风险（基于数据）

| 风险 | 数据依据 | 应对 |
|---|---|---|
| **新客户跑单** | 37% 是 30 天内新号 | 只接注册 >1 年的客户 |
| **未验证客户** | 93% 未验证 | 优先选已验证的 7% |
| **Chargeback 不赔** | Sitejabber 多条投诉 | 单笔不超过 $200 |
| **20% 抽成** | 官方费率 | 报价先加 25% |
| **提现问题** | 多条投诉 | 到账立刻提 |

# 七、最终结论

## **PeoplePerHour = 情报站 + 练手场，绝不是主战场。**

| 用途 | 建议 | 理由 |
|---|---|---|
| 看行情 | ✅ 每周扫 | 免登录，数据真，够新鲜 |
| 练手 | ✅ 3 单以内 | 门槛低，验证交付流程 |
| 主战场 | ❌ 坚决不 | 中位 $90 + 1.3 分 + 37% 新客户 |

**如果只做一件事：把它当"免费市场情报源"用，不投钱不投时间。**
