# 50-知识

**长期有效、不需要决策、不会归档的东西放这里。**

读书笔记、某人档案（客户偏好、同事职责）、项目背景资料、可复用模板和清单、外部原文摘录。

## 判断标准

| 问题 | 答案 | 去哪 |
|---|---|---|
| 三个月后回看还要查吗？ | 要 | **`50-知识/`** |
| 三个月后回看只是历史？ | 是 | 那是想法 → `10-想法池/` |
| 需要我"决定做不做"吗？ | 需要 | 那是想法 → `10-想法池/` |

知识没有生命周期。放进想法池的东西每次整理都会被当成"待处理项"，永远清不掉——所以别混。

## 两条硬规矩

1. 引用外部内容 → 内联 URL，**不改写引用**，并标"截至 YYYY-MM"。
2. 姓名、职责、偏好这类会变的事实，标注**记录的日期**，别当成永久真相。
