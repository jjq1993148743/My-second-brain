# 小红书搜索热度精确采集法

> 用浏览器 DOM 工具（builtin_browser）在**已登录的日常 Chrome** 上读小红书搜索结果页，逐条抓"标题/作者/日期/点赞"，量化某主题的讨论量与爆款曝光，输出排行+打分。截至 2026-09 验证有效。这是 [[养猫选题从共有困惑倒推]] 的落地工具，服务 [[养猫内容执行计划]]。

## 一句话结论
截图目测会严重漏采——只看首屏会把主题的爆款曝光**低估 4–6 倍**（实测"厌食/挑食"从 256→1452、540→2329）。必须用 DOM 精确抓全 ~27 条再取峰值/中位赞。

## ⚠️ 风险分级（和 §0.1 有冲突，先看清楚）
本方法用**登录态浏览器**读页面，严格说落在 AGENTS.md §0.1「登录态爬虫」的禁止项里。
- 缓解：只读搜索结果页、不点赞/评论/关注/发帖、单线程单标签、每词间随机停顿几秒、出现验证码/418 立即停。行为上等同真人浏览，不额外打接口。
- 但这是**我（jjq）明确授权的一次性用法**，不代表可以放开跑量。要扩大规模前，先按 §0.1 重新评估。
> AI 推测：低频只读搜索页触发风控的概率低，但"登录态抓取"这条红线是库规自己定的，是否长期豁免由 jjq 拍板。

## 采集流程（每个关键词重复）
1. `tabs_context` 拿到小红书标签页 tabId；没有就 `navigate` 到 `https://www.xiaohongshu.com/explore` 确认登录（左下角"我"有头像）。
2. `navigate` → `https://www.xiaohongshu.com/search_result?keyword=<encodeURIComponent(词)>`（会重定向带 `&type=51`，正常）。
3. 一次 JS 滚动加载+抽取（ISOLATED world，async 可用）：
   ```js
   (async () => {
     for (let i=0;i<3;i++){ window.scrollTo(0, document.body.scrollHeight); await new Promise(r=>setTimeout(r,1500)); }
     const items=[...document.querySelectorAll('section.note-item')];
     const rows=items.map(c=>{const f=c.querySelector('.footer'); if(!f) return null;
       const lines=f.innerText.split('\n').map(s=>s.trim()).filter(Boolean);
       const like=(c.querySelector('.like-wrapper .count')||{}).innerText;
       return {title:lines[0]||'', like:(like||'').trim(), date:lines[lines.length-2]||''};}).filter(Boolean);
     return JSON.stringify({n:rows.length, rows});
   })()
   ```
4. 换词前停顿几秒，模拟人手；全程一个标签、不并发。

## 关键选择器
- 卡片：`section.note-item`
- footer innerText 按 `\n` 拆 = `[标题, 作者, 日期, 点赞]`
- 点赞：`.like-wrapper .count`（"赞"=0 或新帖；带 万/k 要换算）
- 标题/作者：`.title` / `.author .name`

## 指标口径（小红书不公开浏览量/曝光量）
| 想要 | 代理指标 |
|---|---|
| 讨论量 | 右侧"点点AI 总结N篇笔记"数字 / 卡片密度 |
| 曝光（爆款天花板） | 单条**最高赞** |
| 曝光（是否普遍热，优先看） | **中位赞**，抗噪 |
| 需求信号 | 搜索框**联想词下拉**（如"防软便猫粮/换猫粮/高性价比"直指采购意图） |
| 时间 | 原生筛选只有 一天内/一周内/半年内，**无精确1个月**；新鲜度按卡片日期判 |

打分模型（可调）：综合 = 0.35·曝光 + 0.30·讨论量 + 0.20·近月新鲜度 + 0.15·采购关联。

## 实测样本（养猫症状，2026-09-28，每词27条）
峰值赞排序：呕吐 2054 > 厌食 2329(传腹泛病另计) ≈ 挑食 1452 ≈ 流泪 1416 > 软便 915 > 换季 103。
中位赞排序：呕吐 196 > 厌食 95 > 流泪 73 > 挑食 51 > 软便 45 > 换季 10。
**换季"曝光低"= 应季刚起量、帖子多是几小时/1天内的新帖，赞还没滚起来 → 蓝海窗口，不是没人看。**

## 坑（实测）
- 首屏目测漏千赞爆款，低估 4–6 倍；必须抓全 27 条。
- `navigate` 只支持 http(s)，打不开 `file://` 本地 HTML。
- 综合排序是个性化黑盒，换账号结果会变，只当方向参考。
- 高赞常是老帖沉淀（呕吐 2054 那条是 05-06），别当"近1个月"。
- ISOLATED 与 MAIN 两 world 变量互不可见；抽取用 ISOLATED。
