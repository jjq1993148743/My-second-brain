## 为什么这期换插画风

真实风 AI 画不出"病症细节"——秃块的边缘起屑、人手臂上的环形红疹，这两个是本期的核心信息，AI 实拍味反而会糊成一团肉色。

插画风能把**形状和边界**画清楚，而且不吓人（皮肤病灶的实拍图在小红书信息流里容易被判不适）。

| 项 | 真实风（09–13） | 插画风（本期） |
|---|---|---|
| 病症形状 | 靠文字说，图只给氛围 | **直接画出圆秃的边界、环形红疹的环** |
| 信息流观感 | 猫脸可信度高 | 米色底 + 矢量感，**不血腥不吓人** |
| 模型 | modelscope / zhipu | **flux-1-schnell（插画第一名，3–5 秒/张）** |
| prompt 语种 | 中文 | **必须英文**（flux 不吃中文，见 SKILL §中文/英文怎么选） |

## 这期的核心钩子：跨物种对照

猫癣是**人畜共患**的。这既是本期的差异化，也是唯一的传播点：

- 封面不画"猫的秃块"单独一张，而是 **猫的圆秃 ∥ 人手臂的环形红疹，中间一个等号**
- 这是全系列第一次出现**人与猫同框对照**（13 眼屎多是人和猫在同一个画面里互动，本期是**两个独立主体并列**）
- 钩子从"报档位/报数字"升级成**"你身上有没有"** —— 用户会主动在评论区说"我手上真的有一个"

## 正文

去年冬天，我第一次在啤酒耳朵后面摸到一块秃。

指甲盖大小，圆的，边界很清楚，边上有一圈细白皮屑，中间露出粉色的皮。我当时第一反应是"换毛没换匀"。

过了两周，那块没长回来，还大了点。

真正让我警觉的是我自己的手臂。手腕内侧起了一个圈——边上红，中间反而淡，痒。

那一刻我才把两件事连起来：猫身上一块圆秃，我手上一个红圈，这不是两个毛病，是同一个。

后来去查了，是癣。医生说了一句我当时没太在意、后来反复想起来的话：这个病最难的不是治，是治完。

往下翻。第二张是"像癣 vs 不像癣"的对照——一块块边界清楚的圆秃、边缘起屑结痂、皮肤发红，这几个往癣想；左右对称掉毛、只有屑没有圆秃边界，那是另一类，别都按癣治。第三张讲两个复发原因，一个是"长毛了就停"，一个是只治猫不治环境。第四张是环境怎么处理：吸尘、热水洗、太阳晒，还有立刻要做的隔离。第五张是你在家能做的四步。最后一张说两句实话。

关于"长毛了就停"，我要单独说。毛长出来的时候，真菌往往还在皮肤和毛囊里——外用药杀的是表面的菌，毛囊里的要等毛跟着长出来才被带走。所以那个"看起来好了"的时刻，恰恰是最容易前功尽弃的时刻。按医生定的时间做完，别自己提前停。

还有一件事很多人会漏：癣是人畜共患的。老话里叫"生癣"、"钱癣"、"癞了"，这些说法都对，但从来没说清它会传给人。你身上那个红圈不是巧合，多半就是搂猫蹭来的。人不处理，就和猫互相踢皮球——你好了它又传给你。

也不要用土方。抹蒜、抹醋、抹酒精，刺激皮肤，舔进去还可能中毒；人用的癣药膏尤其含激素的那种，激素会让癣往外扩散。规矩做法只有一句：看一次让医生确认是不是癣、疗程多长，外涂、药浴、口服全部由医院开具并按医嘱用，同时做环境处理，到医生说可以停才停。

症状不等于诊断。掉毛的原因不止癣一个，这里只帮你分方向，最终由兽医确认。本期不涉及任何用药与剂量。

你家是哪种情况？一块圆秃边缘有屑、对称掉毛皮肤不红、还是你身上也起红圈了？评论区报个 1、2、3。报 3 的记得先把猫和人分开，今天就做。

一共 72 条，我一条条写。想看哪条，评论区点单。

关注我，看我怎么把 7 只猫的坑都写成能用的自查表——我们一起来养猫。

## ⚠️ 插画风的两个代价（下次做插画前先读）

1. **两个主体不能一次画**。一开始想一张图里画"猫 + 人手臂对照"，模型必然跑偏。**拆成两张独立生成，再在 HTML 里左右拼接**——这是本期能成功的原因。
2. **pollinations 把 "cat" 理解成"猫娘"**。第一轮生成出了个猫耳少女脸，完全废。**插画风直接走 cloudflare flux，跳过 pollinations**；prompt 里必须写死 `an actual domestic cat`、`a real cat body`，并在 negative 里写 `no human, no people, no anime girl, no cat ears on a human`。

## 待核实（没编造，需你确认）

1. 封面、图 4 是 **AI 插画**，AI 声明必须勾。
2. 正文「去年冬天在啤酒耳后摸到一块秃 / 手腕内侧起了一个圈 / 医生说这个病最难的不是治是治完」——**这三段是全新写的，前面旧稿没有这段**。如果你家实际没有过癣，**整篇必须改写成"我一个朋友"或"很多人会遇到"**，不能用第一人称。
3. 如果确实有过，请补：**是啤酒还是哪只猫？查出来是哪种癣菌？治了多久？** 这三条能让正文从"像故事"变成"是你的经历"。
4. 标题主推 19 字版依赖"我先被传上"这个反转，如果你家实际是猫先有、你后有的，顺序要调过来。
