## 医学边界

- **不给药名、不给剂量、不讲治疗**。反复写"补什么补多少只能由宠物医院开具并按医嘱使用"。
- 不恐吓：用"当天出门""急诊方向"分级，不写"会死"。
- 文献在「引用文献」栏：
  - 《猫病学》第5版 第1篇 第114条「低钾血症」、第105条「高钾血症」、第193条「慢性肾病」、第109条「甲状腺功能亢进」、第101条「原发性高醛固酮血症」
  - 《2026 iCatCare 猫慢性肾病诊断与管理共识指南》第5/8节——第5节原文已列英文+中文，第8节只列条目名不摘句。
- "垂头多半不是脖子的事，是钾掉太狠肌肉没劲"是底表专业病症名的反常识句，转述为"肌肉撑不住、内科不是骨科"，不渲染确诊。
- "托下巴测试"是底表自测第 1 条，转述为"托着舒服手松又掉 = 肌肉撑不住"，不自行升级为诊疗。
