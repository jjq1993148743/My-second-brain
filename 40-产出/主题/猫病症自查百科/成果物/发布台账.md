## 选题不直观怎么办（2026-11-16 方法论沉淀）

黑下巴原被废弃，理由是「用户看不出黑下巴长什么样」。复活后的解法，可复用到其他"不直观"选题：

| 问题 | 解法 |
|---|---|
| 症状名是行话，读者不知道指什么 | **标题换成画面描述**：「黑下巴」→「下巴一排黑点」 |
| 读者不知道自己家猫有没有 | **封面用同一部位左右对照**（干净 vs 病灶），0.5 秒认出来 |
| 原因抽象（碗脏） | **给微距实拍感底图**，让读者"翻自己家的碗" |
| 不确定该不该处理 | **三档分级 + 天然测试**（做三天看趋势） |

**判断标准**：如果这个症状名念出来，脑子里**没有画面**，就一定要走「左右对照 + 画面化标题」，不能只靠文字解释。

## 选题"认知是反的"怎么办（2026-11-16 新增，来自 10 多饮多尿）

多饮多尿的难点不是不直观，是**读者以为这是好事**（"多喝水健康"）。这类选题的解法：

| 问题 | 解法 |
|---|---|
| 读者把病当好事 | **把观察对象换掉**：不看"猫喝水"（正常行为），改看"猫砂结块"（异常证据） |
| 说不清"多"到什么程度 | **给可算的公式**：体重 × 40ml = 一天参考上限 |
| 读者觉得"观察就行" | **明说这是记录题不是调理题**，把"记录"本身包装成解决方案 |
| 容易误判 | **三个信号叠加**（结块 + 水量 + 体重），单看一个不算 |

## 选题"分两类、方向相反"怎么办（2026-11-17 新增，来自 12 尿砂）

这是第三种题型，比前两种更危险：**读者不知道还好，知道一半最糟**。尿砂分磷酸铵镁（能靠饮食溶掉）和草酸钙（吃什么都溶不掉），照错方向买粮**会越喂越糟**。

| 问题 | 解法 |
|---|---|
| 读者以为"多喝水就能冲掉" | **不给通用建议，先给分类**：全篇第一张核心图只做"两类方向相反"对照 |
| 讲了分类，读者还是会直接买 | **明确写"本期不推荐任何一款粮"**，把"不推荐"当卖点（可信度反而更高） |
| 分类名是行话（struvite / calcium oxalate） | 中文名 + 英文名双标，**中文名用"能溶 / 溶不掉"当引导**，不用"磷酸铵镁 / 草酸钙"做首屏 |
| 读者看完还是不知道自家是哪类 | **给在家可做的三处**（捻砂 / 接尿看沉底 / 记发作日历），把"去医院查"变成"先攒证据" |

**判断标准**：如果这个症状的处理办法**不是唯一方向**（分型、分阶段、分病因），就必须走「先分类再谈办法」结构，不能给单线建议。

## 选题"有一个不可逆的错误做法"怎么办（2026-11-17 新增，来自 13 眼屎多）

第四种题型，也是**最值得单独拿一张图去讲**的题型：症状本身多数不致命，但**读者手里那个"顺手的办法"会造成不可逆后果**。眼屎多就是典型——家里有人用眼药水，名字带"松"的一滴就可能把可治的角膜溃疡推向穿孔。

| 问题 | 解法 |
|---|---|
| 读者手里已经有一个"顺手的错办法" | **单独一张图讲"为什么不能"**，不要塞进"建议清单"里当一条 |
| 讲风险容易变成恐吓 | 用**机制表述**：「激素压住炎症反应、加速角膜软化，从能治变成穿孔」，不说"会瞎" |
| 只否定会让读者不敢处理 | **否定之后必须紧跟正确顺序**：「等医生确认没有溃疡，再谈用什么」 |
| 唯一提到的药名是为说"禁用" | 明确标注「本期不涉及任何用药与剂量」，避免被理解成推荐 |

**判断标准**：如果这个症状存在**一个"很多人都这么做、但做错就不可逆"的动作**，就单独给它一张图，并且把"正确顺序"跟"禁止动作"写在同一张图上——只说禁止等于把人卡死。

## 选题"会传染给人"怎么办（2026-11-17 新增，来自 14 猫癣）

第五种题型，也是**传播性最强**的题型：病本身在猫身上不算重，但它**能传给主人**。这一条把读者从"看客"变成"当事人"，评论区会自己长出内容（"我手上真的有一个"）。

| 问题 | 解法 |
|---|---|
| 读者只关心猫，不关心自己 | **封面把人和猫并列**：猫的圆秃 ∥ 人手臂的红圈，中间一个等号。封面就把"这是同一件事"说完 |
| 说了会传人，容易被当成恐吓 | 用**亲历口吻**：「我手腕内侧起了一个圈，那一刻我才把两件事连起来」——不是警告，是自述 |
| 读者会问"那是谁传给谁" | **明确写"别纠结谁传谁"**，一起查、一起处理才停得下来（纠结顺序只会拖延） |
| 人这边容易被忽略 | 单独一条：**皮肤科和宠物医院是两件事，都要做** |

**判断标准**：如果这个症状**能传给人**（人畜共患、真菌、寄生虫），封面就必须出现人，且是"同构对照"（同一形状出现在两个物种身上），不能只画猫。

## ⚠️ 插画风的执行约束（2026-11-17 新增，来自 14 猫癣踩坑）

| 坑 | 现象 | 解法 |
|---|---|---|
| **两个主体不能一次画** | 想一张图画"猫 + 人手臂对照"，模型必然跑偏（出成人脸、出成两只猫） | **拆成两张独立生成，再在 HTML 里左右拼** |
| **pollinations 把 cat 理解成猫娘** | 出了个猫耳少女脸，完全废 | 插画风**直接走 cloudflare flux，跳过 pollinations** |
| 主体必须写死 | 只写 "cat" 会被自由发挥 | prompt 写 `an actual domestic cat` / `a real cat body`；negative 写 `no human, no people, no anime girl, no cat ears on a human` |
| prompt 语种 | flux 不吃中文，中文会归零路由到别的模型 | **插画风 prompt 必须英文**（SKILL §中文/英文怎么选） |

## 选题"症状是已知的，但因果反常识"怎么办（2026-11-17 新增，来自 16 猫鼻支）

第六种题型。前面五种都是"读者不知道自己有没有"，这一种相反：**症状读者早就知道了**（打喷嚏、流鼻涕谁都知道），真正的信息增量在**一个反常识的因果链**。

猫鼻支就是这样：大家都知道猫会打喷嚏，但很少有人知道**"猫不吃饭"是因为闻不见**。

| 问题 | 解法 |
|---|---|
| 症状是常识，写出来没有增量 | **把"结果"提到主位，把"症状"降级成背景**：不提"打喷嚏怎么办"，提"满碗不吃不是挑食" |
| 因果链要一次性说清 | 封面就用**否定式画面**：猫低头看着**满碗**却不吃。三个人 0.5 秒就懂 |
| 读者会问"那我怎么确认" | **给一个 10 厘米动作**（闻味测试）——一个动作、一个距离、一个二选一结果 |
| 反常识容易显得抬杠 | 用**第一人称踩坑**打底：「我一直以为猫不吃饭是嘴刁了」→ 建立共情再反转 |

**与第四种题型（有不可逆的错做法）的区别**：第四种的核心是"别做某件事"（别滴激素眼药水）；这一种的核心是"别误判某个因果"（不是挑嘴，是闻不见）。**前者单独给一张图讲禁止，后者把因果写进标题。**

**判断标准**：如果这个症状**人人都知道名字，但普遍搞错了它的原因**，就走「否定式画面 + 因果进标题 + 一个验证动作」这套。

## 日系清新风的执行要点（2026-11-17 新增，来自 16 猫鼻支）

flux-1-schnell 是日系清新的第一名（见 free-text-to-image SKILL 路由表）。三个实测要点：

| 要点 | 做法 |
|---|---|
| prompt 必须英文 | 中文会让路由跳过 flux（SKILL §中文/英文怎么选） |
| **关键词只写四类** | `Japanese airy photography style` / `muted low-saturation palette` / `soft diffused window light` / `film-like softness` |
| 负空间要主动要 | 写 `minimal clean background with lots of negative space`，否则 flux 会塞满画面 |
| **不画人、不画多主体** | 沿用 14 的教训：多主体拆开生成；negative 加 `no human, no people, no anime girl` |


## 选题"有病灶但不适合实拍"怎么办（2026-11-17 新增，来自 17 口臭）

第七种题型。前面六种都能用真实照片或干净插画解决，这一种不行：**病灶本身在信息流里会被判不适**（牙龈红肿、溃烂、流脓、流血的局部特写）。

| 问题 | 解法 |
|---|---|
| 真实病灶图会被限流 | **换黏土 3D**：把红线和结石做成"玩具色块"，萌感和信息量同时保住 |
| 画面可爱会被当成儿童内容 | 标题**必须带症状词和判断**（"不是老了正常""抬唇三秒"），把调性拉回严肃 |
| 需要看清"那一圈红线" | 黏土反而更清楚：**色块对比比实拍更直观** |
| 读者不知道该看哪 | **用局部动作放大**（只拍嘴+手指抬唇），不拍整只猫——信息密度最高 |

**判断标准**：如果这个症状**必须有病灶特写才说得清，但特写会让人不适**，就换黏土 3D + 局部动作放大，并在标题里用判断句把调性拉回来。

**与第二种题型（认知是反的）的区别**：那种要"换观察对象"（看结块不看喝水）；这种不用换对象，**只需要换渲染方式**。


## 重题材怎么用"底色"降速（2026-11-17 新增，来自 18 猫瘟）

第八种题型。前面七种都是"帮读者处理"，这一种是"帮读者认清有多重"。**它最大的风险不是没流量，是掉信任**——写轻了不负责，写重了像贩卖焦虑。

| 问题 | 解法 |
|---|---|
| 读者看不出这篇和前 17 篇不一样 | **换底色**：全系列第一次用深墨蓝黑。深色在这里不是审美，是信息 |
| 恐吓感太强会被反感 | 用**可量化时间**替代形容词：「十几个小时」而不是"很快""极快"；不写"会死""没救" |
| 太轻会让读者误判 | 核心句必须硬：「家里没有第二条路，所有办法都在医院里」——不留模糊空间 |
| 容易编造经历来共情 | **明确禁止编造"我家猫得过"**。这种病编造会真的伤人，也容易被识破 |

**判断标准**：如果这个症状**读者会真的失去猫**，就走「深色底 + 可量化时间 + 不留退路的核心句」，并且**绝不为了流量加重**。数据差可以接受，信任掉了回不来。

**排期铁律**：两个重题材之间**至少隔两篇轻的**，否则整个账号调性变灰。
