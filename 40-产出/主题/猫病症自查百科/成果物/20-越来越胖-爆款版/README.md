## 医学边界

- **不给药名、不给剂量、不讲治疗**。
- 不恐吓：用"减到理想体况本身就是防病"这种可量化表述，不写"会死""肾衰竭"。
- 肥胖是"慢性健康问题"（糖尿病等），引用 2021 AAHA/AAFP 猫生命阶段指南原文（Free-choice feeding 容易过量；超重/肥胖 predispose 慢性病）。
- 引用文献：《猫病学》第5版 第1篇第154条「肥胖症」；《2021 AAHA/AAFP 猫生命阶段指南》(JFMS 2021)。
- 三条"例外"（肚子鼓四肢瘦 / 内科 / 未绝育母猫）都是底表「警示」栏原文转述，用来分流，不是诊断。
