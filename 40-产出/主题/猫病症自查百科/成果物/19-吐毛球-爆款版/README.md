**「吐出来的没多少毛，主要是黄水——这不是毛球。」**

## 正文要点

- 一句话判断：拨开吐出物，**一团毛=真毛球，黄水/没消化粮=不是毛球**
- 两条正路：**多梳**（长毛每天、短毛一周三次、换毛季提前一周）+ **加纤维必须加水**
- 两个坑：化毛膏天天挤=喂油加糖；化毛膏+换粮一起上=不知道哪个起作用
- 四个警惕信号：全年不断吐 / 掉秤 / 舔秃 / 便秘腹胀 → 不是毛球的事
- 医学边界：不给药名剂量，最终由兽医排查，AI 声明句已埋
