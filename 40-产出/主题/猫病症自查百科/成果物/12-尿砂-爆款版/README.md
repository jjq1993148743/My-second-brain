## 为什么这期难做

不是不直观，是**读者的认知是错的**。多数人以为「尿里有砂」= 多喝水就能冲掉。真相是：它分两类结石，**处理方向完全相反**——一类能靠饮食溶掉，另一类吃什么都溶不掉。

这决定了本期的核心手法不是"教你怎么办"，是**先把"不能乱办"这件事说清楚**。

| 坑 | 本期的解法 |
|---|---|
| 读者以为这是好事/小事（"多喝水就行"） | 把观察对象换掉：不看"猫喝不喝水"，看**铲砂时指尖有没有研磨感** |
| 两类结石方向相反，讲不清就误导 | **第二张整张只讲这一件事**，双卡对照 + "方向搞错越喂越糟" |
| 容易被当成"该买处方粮了" | **全篇不给任何一款粮**，只教"先分清哪一类" |
| 与 07 尿血、11 尿闭撞系统 | 07=有血、11=没尿、12=有砂；三篇是同一系统的三段，可互引流但不连发 |

## 正文

铲起来的那一下，指尖捻到一层沙。

不是结块，是那种细细的、有研磨感的颗粒感，沾在指腹上捻不干净。我当时第一反应是猫砂受潮了，换了新砂，一个星期又出现。

网上说"多喝水就行"。我信了，换了饮水机、多加了一个水碗，看着它一天喝好几趟，觉得这事过去了。

真正让我警觉的是三个月后翻相册——同一只猫、同一个猫砂盆，那些带砂的尿团照片，从一年一张变成一个月一张。

后来我用白瓷小碗接了一次尿，静置十几分钟，碗底沉了薄薄一层细沙。

那时候我还不知道，尿里有砂、沙子尿、膀胱结晶这些说法指的是同一件事，更不知道它会分成两类，而这两类的处理方向正好相反。

往下翻。第二张是全篇最重要的一张：磷酸铵镁能靠饮食溶掉，草酸钙吃什么都溶不掉。第三张是在家能做的三处——铲砂时捻一下、接一次尿看沉底、把发作日期标在日历上。第四张是五类优先级排前面的猫：公猫、中年偏胖纯干粮喝水少、波斯系喜马拉雅、反复泌尿道感染、长期自制饭或来路不清的粮，中三条以上就开始记。第五张是该做三件和别做三件。最后一张说清为什么这期比前两期绕。

所以我没在这里推荐任何一款粮。石淋、砂淋、"排石粮"这些词我一开始全都没对上号，现在知道了：先弄清是哪一类，再谈喂什么，这个顺序反了，钱和时间都白扔。

但我要说清楚：碎屑一旦把尿道堵上，就从"尿砂"变成"尿不出"，那是几个小时的事，不是几个月的事。盆里完全没有新结块、频繁蹲盆还使劲的，别在家测了，按急症走。反复膀胱炎好不利索的，也不是换粮能解决的。

症状不等于诊断，这里只帮你分方向，最终由兽医排查。本期不涉及任何用药与处方粮推荐。

你铲砂的时候捻过结块吗？有研磨感的、摸到过沙粒的，评论区报个"有"，我帮你捋该先做什么。没捻过的，下次铲砂试一下——这是最便宜的一次筛查。

一共 72 条，我一条条写。想看哪条，评论区点单。

关注我，看我怎么把 7 只猫的坑都写成能用的自查表——我们一起来养猫。
