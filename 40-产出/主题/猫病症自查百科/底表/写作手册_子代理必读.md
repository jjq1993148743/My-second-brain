# 《猫病自查表》写作手册（子代理必读）

你是这套表格里一个条目的作者。**先完整读完本文件，再动笔。**

---

## 一、要写成什么样：12 列，一条一个竖向表格

每条用一个三级标题（### 序号）开头，然后一张两列表格，行名固定、顺序固定，共 12 行：

```
### 20

| 列 | 内容 |
|---|---|
| 序号 | 20 |
| 最常见叫法 | **两个字的口语，主人第一反应会说的那个词** |
| 其他叫法 | **通用**：…<br>**老话／地方别名**：…<br>**网上说法**：… |
| 主人可识别的现象（生活场景） | **有对比的，前后都摆出来；突然冒出来、没有从前参照的，就直接写现在。**<br>· 以前…；现在…。<br>· 以前…；现在…。<br>· 只有现在、没有从前参照的：… |
| 专业病症名 | …（一句纠正认知最好，如"'乱尿'常常不是行为问题，是疼"） |
| 引用文献 | ①… ②… ③… |
| 具体位置+原文 | ① …（逐字原文＋中译）<br>② … |
| 谁更容易得 | 1. …<br>2. …<br>3. …（年龄／品种／性别揉在每条里，不要再拆小标题） |
| 在家怎么自测 | 1. **测试名**：怎么做＋怎么读结果<br>2. …（至少 3 条，写动作，不写医院项目） |
| 建议（3条） | 1. …<br>2. …<br>3. …（只给 3 条，纯主人动作） |
| 警示（含品种方向） | · …<br>· …（只有"八成是A、两成是B"这种混合情况才写；指向明确就写"这一条方向明确，不必往别处猜"再给最易混的一件事） |
| 老炮备注 | 1. …<br>2. …（**至少 5 条，按猫的真实习性写，居家能操作，基本不提就医**） |
```

## 二、硬性禁忌（违反即返工）

1. **禁止跨条引用**：不许写"见第 X 条""参见上表""转去看泌尿那条"。每一篇都是独立文章。
2. **禁止编造引文**：只有你**真的抓取到原文**才能加引号。取不到就写"（本次未取得正文，只列文献名与年份，不摘原句）"。
3. **不写检查项目**：建议列里不许出现"血检、生化、B超、X光、尿培养、测血压、切片"等。一律写"当天带去看""一周内安排一次看诊"。自测列只写家里能做的事。
4. **不制造焦虑**：不用"会猝死""来不及就死了"。急症写成"当天处理，不要观察过夜"。紧迫程度和"哪种猫更耗不起"这类话放到**老炮备注**里。
5. **老炮备注不夹专业词和英文**（全表允许出现的英文只有：文献名、逐字原文、以及一个必要的缩写）。要写猫的生理与行为机制＋具体动作，例：
   - 好：猫是先闻再吃，鼻子不认就不张嘴 → 喂前加一点温水拌。
   - 好：它是"一口气吞"的猎食型，牙不细嚼 → 粮在平盘摊薄一片。
   - 好：胡须比嘴娇气，深窄碗戳胡须它别扭 → 换宽口浅盘。
   - 好：尿渍要用酶类清洁剂，别用 84（含氯带氨味，反而催它在同一处补）。
   - 坏：建议给予低脂处方粮并监测体重（太像医嘱）。
6. **风险归因要谨慎**：不许写"某款猫粮导致××"。营养性问题一律写成"长期单一自制／来路不明粮"这类可核实的方向。
7. **用药**：必须写"由宠物医院开、按医嘱用"；**禁止**出现任何"人药给猫"的建议，可以写"家里那几种退烧止痛药对猫都可能致命，别自己给"。

## 五、范文（这是已定稿的第 11 条，照这个颗粒度写）

### 11（节选）

- **最常见叫法**：尿血
- **其他叫法**：通用：乱尿、尿在外面、频繁上厕所、尿团变小｜老话／地方别名：尿淋、"热尿"、尿不净、"滴尿"｜网上说法：应激性膀胱炎、报复性尿床、粉色猫砂、"到处做记号"
- **现象**：以前一直好好用盆；现在尿在床上、沙发上、地毯上、洗衣机里。／以前一天两三团；现在一天七八次、每次只指甲盖大的一点。／以前进盆几十秒就出来；现在蹲在盆里很久、使劲、结束时"喵"一声。／只有现在、没有从前参照的：尿在墙上、家具竖面上（不是"做记号"，是憋不住）；夜里反复进出猫砂盆；精神食欲基本正常，但厕所行为整个变了。
- **专业病症名**：猫下泌尿道疾病（这一组现象里最主要的是特发性膀胱炎）。**"乱尿"常常不是行为问题，是疼**
- **在家怎么自测（第 1、2 条示例）**：1. **看"次数多、每次少"这个组合**：一天进出七八次、每次一小点，基本可以直接归到这条线。2. **确认红色是不是血**：临时换成无香白砂，或用白色纸巾接一点。有些猫砂会把尿染成粉，别自己吓自己；一旦确认是真血，就别再在家观察。
- **建议（3条）**：1. 当天带去看一次：肉眼可见的血、蹲盆使劲、精神食欲一起变差，任何一条出现就别等。2. 家里立刻做减压三件事：猫砂盆按"猫的数量加一个"增设并每天铲两次；水点分散到各房间；食、水、厕分开摆，别挤在一处。3. 把干粮的一部分换成湿粮、粮里加点温水——这是全家最容易做到、也最省钱的护膀胱动作。
- **老炮备注（节选）**：1. **它不是记仇。**膀胱炎让猫憋不住、疼，它找柔软的地方是想找个不硌的地方；骂和"按头闻"只会让它更不敢进盆。2. 尿渍用酶类清洁剂泡，别用 84：含氯的味道里有氨味，反而更像尿，它会接着在同一处补。

## 六、交付

- 一个 Markdown 文件，只含你负责的 5 条，条目之间空一行，顺序按序号升序。
- 不要写前言、总结、注释，不要加"以下是…"这类话。
- 每条 12 行行名必须一字不差：序号／最常见叫法／其他叫法／主人可识别的现象（生活场景）／专业病症名／引用文献／具体位置+原文／谁更容易得／在家怎么自测／建议（3条）／警示（含品种方向）／老炮备注。
