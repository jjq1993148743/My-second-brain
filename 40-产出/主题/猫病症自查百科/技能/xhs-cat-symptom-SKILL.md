# 猫病症自查百科 · 小红书笔记生产

## 定位（动手前先读）

- 1 个症状 = 两期（一期判断 / 二期怎么办），共 9 张图 + 2 份发布文案
- 差异化只有两条：**主人动作颗粒度**（今天在家就能做的测试）+ **文献出处**（每条结论可溯源）。不打专业度、不装兽医
- 人设：**不会写代码的铲屎官不是好厨子 —— 爱用数据说话，全网搜罗养猫心得，记录在此，希望对余华们有所帮助**。忌焦虑钩子、忌"一站式解决"式客服腔
- 竞品实采锚点（2026-10-07，三词 85 条）：颜色对照科普是红海（头部 6205 赞），但 0/85 有自测动作、0/85 有出处、0 决策树、0 三色分流——错位竞争，不硬碰"颜色对照"主题

## 生产流程

1. **定形态**：查 § 症状分档，科普词走决策树模板，急症词走急救分流模板
2. **取材**：读 `40-产出/主题/猫病症自查百科/底表/猫病症自查大表_全72条_12列_20261008.md` 对应条目（12 列全量用；行号查 `底表/症状索引.md`，**别整表读**，整表 22 万 token）。条目不在 72 条内 → 先按该表 12 列格式补条（文献先行；《猫病学》5版写全"第5版第1篇第N条"；原文取不到就退 europepmc / msdvetmanual 抓摘要，全失败只留篇+条并注"未取正文"，禁编引句），补完再进下一步
3. **导图**：按 § 三色决策树规范 写自包含 HTML → chrome headless 截 PNG
4. **正文+标题**：按 § 页面结构 写
5. **自检**：过 § 红线清单 + § 同质化防御（互换测试），全过才交付；导图必须 Read 看图复核
6. 产出存 `40-产出/主题/猫病症自查百科/成果物/{两位序号}-{症状名}/{一期|二期}\`：每期 = 图 PNG + 同名 HTML 源 + 发布文案.md

## 症状分档（决定模板与标题）

- **科普词**（呕吐、软便、不吃东西、掉毛、眼屎多、口臭…）→ 决策树模板；标题含"自查/在家怎么验证"
- **急症词**（尿血、尿不出来、中毒、后腿突然没劲、抽搐、呼吸困难、误食线…) → 急救分流模板；标题含"黄金24小时/这几种马上就医"；第一屏就是红色就医线，不许铺垫
- 选题池：78 条精简表 A 层 31 条症状入口（`猫病精简表_主人可感知版_20261007.md`），按热度排：呕吐>厌食>流泪>挑食>软便>换季

## 三色决策树规范

- 中心 = 情绪钩子短语（"我家猫吐了"），不是病名
- 主干 ≤3 层：看到什么 → 在家验证（哪个测试）→ 走哪条路
- 叶子 = 三色结论：**绿=在家调**（给具体动作）/**黄=记账观察**（给记录法+观察天数）/**红=当天就医**（给一句话理由）
- 图上只留人话+动作；文献出处放图底部一行小字（2026-10-09 起不再单独做证据页）
- 画布 1242×1656（3:4 竖图）；SVG 的 fill/stroke 写死色值禁 `var()`（渲染成黑）；图标用 CSS 圆点禁 emoji（headless 截图变方框）；禁英文术语
- 截图：`chrome --headless=new --force-device-scale-factor=2 --window-size=1242,1656 --screenshot=out.png file:///路径`；截图后 Read 看图检查：三色对不对、文字溢出、undefined/NaN

## 页面结构（定稿 2026-10-09：每病症 = 两期，共 9 图）

**一期 · 判断（3 图）**——读者的念头是"我家猫这是咋了？要不要紧？"：
1. **tree 分档**：情绪提问开场 → 三色分支（在家调 / 去排查 / 当天去），叶子只放症状词
2. **决策树**：三列「以前 ｜ 现在 ｜ 该咋办」，逐行对号入座，结论落到 观察 / 调整 / 送医
3. **N 个自测**：在家就能做的验证动作，每条"怎么做 + 怎么读（两个结果分支）"

**二期 · 怎么办（6 图）**——读者的念头是"那我现在到底该做啥？"：
1. **谁更容易中招**（年龄 + 品种档卡，底部声明"概率提示，不是诊断线"）
2. **吐、咳、反流别搞混**（逐行对比，读者最容易踩的坑）
3. **一周吐几次算不正常**（分档 + 记账四样）
4. **先做这一件事**（喂法 3 条 + 时间线）
5. **你管它叫什么**（其他叫法 / 方言 / 网络说法，共鸣 + 吃搜索词）
6. **小技巧**（老炮 9 条，全篇题眼，收尾"没有一条是买什么，全是怎么喂"式）

**通用规范**：
- 每张图顶部先给**情绪钩**（一句人话接住读者的心），再上工具；**情绪钩每条必须重写，禁同一句式**（见 § 同质化防御）
- 画布统一 **1242×1656（3:4 竖图）**；SVG 的 fill/stroke 写死色值；底色自带语义（绿#2e9e5b 黄#f0a52e 红#e5484d）；禁图例、禁"绿黄红"字眼、禁 emoji、禁英文术语
- 正文完整句，禁电报体；单卡 ≤4 行，偏长砍 1/5；行按"从常见到危险"排
- 底部落款人设 + 免责（"症状不等于诊断，最终由兽医排查"）
- 不上图的栏：序号、其他叫法（埋进标签和标题关键词吃搜索流量）
- **不做栏目目录页**（2026-10-09 用户砍掉）

**发布文案**（每期一份 .md）：标题 3 选 1（搜索词前置，**两期后半句必须各不同**防平台判同质）+ 正文（还原那一秒的慌→一句话结论→图导览→该做什么→声明+出处→预告下一期）+ 标签。发布节奏：隔天一期，别同天连发抢流量。

## 红线（写死，违者重写）

1. 症状 ≠ 诊断：所有"如果你家猫 X →"结尾落到"由兽医排查"，不给单一病因结论
2. 禁提检查项、不制造焦虑；紧迫话术只进警示区/红色叶子，不进标题、不进正文开头
3. 用药必须医院处方；禁提人药给猫
4. 每条独立成文，禁跨条引用；出处写全称
5. "猫粮导致××"类归因不采信（2026 版犬猫运动功能障碍指南明确排除合规猫粮）
6. 禁英文术语；禁夸大承诺词（一站式/包治/彻底解决/根治）
7. 内容不得暗示"我试过"——单猫局限，信任靠方法论透明（翻了什么、出处哪条全交代）

## 同质化防御（2026-10-09 新增，与红线同级，违者重写）

**判定机制（先搞懂再动手）**：平台判的是「**句式 / 结构 / 高频词组合**」，**不是主题是否相同**。
不同症状用同一套模板**不违规**；违规的是**"套用模板来做号"**——小红书 2026-04《AI 内容治理规则》明文反对「借助 AI 大批量制作同质化内容」「套用模板来做号」，鼓励「有审美性 / 有叙事特性 / 有信息增量」。
（口径：平台治理规则原文 + 第三方检测工具实测；**官方不公开相似度算法与阈值**，下述数字非官方值。）

**分层处理（哪些能复用、哪些必须变）**：

| 层 | 处理 |
|---|---|
| 版式（tree / 决策树 / 自测 三件套）、配色、字号、人设落款 | ✅ **照旧复用**（效率就在这，平台不判"排版相同"）|
| 症状、现象、人群、文献 | ✅ **天然不同**（72 条大表逐条取材，这是我们的优势）|
| **开头第一句、图导览句式、标题句式、收尾句** | ⚠️ **每条必须重写，禁同一句式** |
| 免责声明（症状 ≠ 诊断…）| ✅ **原样保留**（合规优先，平台认它是好事）|

**互换测试（交付前必做）**：把本条文案里的症状词抠掉，换成另一个症状——
**读起来毫无违和、直接能用 ＝ 同质化，重写**；读起来别扭、必须改 ＝ 合格。

**图片会被怎么检测**：
- 图像指纹（感知哈希）只用于判**盗图 / 搬运**，比对像素 → 版式相同**不触发**
- **OCR 会读图上的字** → 图上的文案同样进文本比对 → 图上文字也要防同构
- 禁每条都用「X 个自测」「先分 N 档」这类**完全同构的标题句式**

**AI 标注（2026-04-01 起强制，两层都要）**：
1. 发布页**勾选 AI 声明**
2. **可见标识**：图文标在标题下方或文末
- 只做一层，可能被判"未标注" → 未标注的 AI 内容会被平台**强行打标 + 限制展示**
- **标注本身不是降权理由**；真正限流的是同质化与"内容里没有人"

**留人味（防"没有人的内容"）**：每条至少留一处 **AI 给不出来的**——真实经历 / 踩过的坑 / 个人判断。
⚠️ 与红线 7 冲突时的取舍：红线 7 禁"暗示我试过"（单猫局限），所以人味走**"翻了什么、出处哪条全交代"的方法论透明**，不走"我家猫试了有效"。

**数字口径（第三方实测，非官方）**：原创性权重 ≥30%；重复率 >15% 影响收录；同质化评分 >35% 明显拖流量，<15% 正常。

**发布后自查**：发布 2h 内曝光比账号均值低约 20% → 大概率暗限流，回查同质化 / AI 味 / 敏感词 / 标题合规。
