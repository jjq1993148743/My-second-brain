## 4. 绘画表达思路（怎么做出一张能看的图）

### 4.1 画布与底色

- **1242×1656（3:4）**，`--force-device-scale-factor=2` 输出 2484×3312
- 底色：四列全链用暖白 `#faf9f7`；其余用纯白 `#ffffff`
- 卡片：白底 + 1px 描边 `#e3e0da`，圆角 12–18px
- 安全边距：左右 ≥24px（四列全链左列贴 24px），上下留白靠**整体居中**产生

### 4.2 三色语义（写死，禁 `var()`）

| 语义 | 主色 | 底 | 边 |
|---|---|---|---|
| 可在家调理 / 绿 | `#2e9e5b` | `#e3f2e8` | `#2e9e5b` |
| 记两周 / 观察 / 黄 | `#f0a52e` | `#fdf3dd` | `#f0a52e` |
| 当天去医院 / 红 | `#e5484d` | `#fbe3e3` | `#e5484d` |

**禁图例、禁"绿黄红"字眼** —— 底色自带语义。行按「从常见到危险」排。

### 4.3 字号阶梯（1242 宽基准）

| 元素 | 字号 |
|---|---|
| 情绪钩 `.hook` | 36px / 800 |
| 主标 `.h` | 44–48px / 900 |
| 主标副句 | 22–24px / 400 / `#888` |
| 列头 `.th` | 26–27px / 800，胶囊底 `#f0ede8` |
| 症状名 `.t` | 29–31px / 800 |
| 症状细节 `.d` | 24–26px / `#777` |
| 原因 `.why` | 25–27px / `#444` |
| 结论词 `.fix b` | 30–32px / 800 |
| 步骤 `.fix span` | 24–26px |
| 脚注 `.foot` | 20–22px / `#4a5568`，底 `#eef1f5` |
| 根节点 `.root` | 38px / 800，底 `#333` |

**已知取舍**：正文 24–27px 折算到 1080 宽是 21–24px，低于平台长图建议的 ≥32px。要真到 32px 只能砍掉「可能是什么原因」整列 —— 这是 v2.0 的刻意选择，不是疏漏。

### 4.4 布局铁律

- **内容按高度紧凑排 + 整体居中**。`body{display:flex;flex-direction:column;justify-content:center;padding:0 48px}`
- ⛔ 主内容区**不许用 `flex:1`** —— 会被撑宽、行距变大、显得空
- ⛔ **不许用 `space-evenly`** —— 元素会被拉开、显得散
- 3:4 画布上，1:1 内容靠**上下留白**居中，不要重排
- 四列全链版式：根节点（左中，宽 150）→ 具体症状（宽 340）→ 可能是什么原因（宽 320）→ 下一步怎么做（宽 324）；行高 236–247px、行距 18–20px；SVG 画连接线（`C` 曲线从根出发，直线连列与列之间）

### 4.5 四列全链的写法（本栏目最强的一张）

- **具体症状**：必带生活画面细节（"饭后半小时内准吐，猫粮还是一粒粒没泡开；吐完跟没事一样，扭头又要吃"），否则读者"没法对号入座"
- **可能是什么原因**：口语化，**禁分号、禁行话**，只给方向不下诊断。格式 `**结论词。** + 一句人话解释`
- **下一步怎么做**：结论词直写（可在家调理 / 记两周看趋势 / 当天去医院），下面跟一句具体动作
- 单卡 ≤4 行，偏长砍 1/5；文案完整句，禁电报体

### 4.6 技术坑（踩过的）

- SVG 的 `fill`/`stroke` 写死色值，**禁 `var()`**（渲染成黑）
- 图标用 **CSS 圆点**，禁 emoji（headless 截图变方框）
- **颜色类与子元素类同名会串色**（改名）
- **flex 容器混排 `<b>` 会拆字**（改块级）
- 截图后**必须 Read 看图复核**：溢出 / 孤字 / undefined / NaN
- 截图命令：`chrome --headless=new --disable-gpu --no-sandbox --force-device-scale-factor=2 --window-size=1242,1656 --screenshot=$TEMP/out.png "file:///C:/完整/Windows/路径.html"`
  - ⚠️ `file:///` 后面必须是 **Windows 式路径**（`C:/...`）；用 MSYS 式（`/c/...`）会变成 `file:////c/...` 报 `ERR_FILE_NOT_FOUND`
  - ⚠️ 输出先落 `$TEMP` 再 `cp` 回中文目录

### 4.7 情绪封面（一期图0，2026-10-10 新增）

- **版式固定**：大字情绪钩（82px / 900，第一行黑、第二行红）+ 主标（44px / `#e5484d`）+ 短横线 + 3 档色块（沿用绿黄红语义）+ 人设落款。左右 padding 92px。
- **大字写法 = 具体场景 + 我的反应**，两行。
  - 01 例：`半夜那声“呕”，` / `我从床上弹了起来。`
  - 02 例：`它闻了一下就走。` / `我以为是粮的问题。`
- **禁写病名**。封面勾情绪，标题吃搜索，两件事分开做。
- 三档色块文案**每期必须重写**，禁与上期同字：
  - 01：在家调：多数是喂法闹的 / 去排查：先记两周再看 / 当天去：这几种不能等
  - 02：在家调：先停加餐、改喂法 / 记三天：拍下来带给医生 / 当天去：连水不喝就别等

## 5. 内容结构（两期 11 图）

### 一期 · 判断（5 图）—— 读者的念头是"我家猫这是咋了？要不要紧？"

0. **情绪封面** —— 信息流专用（见 §4.7）：大字情绪钩 + 主标 + 3 档色块
1. **四列全链 A · 先在家**（5 行，绿 3 + 黄 2）—— 不到急症的
2. **四列全链 B · 别在家拖**（5 行，黄 1 + 红 4）—— 得找医生的
3. **决策树** —— 三列「以前 ｜ 现在 ｜ 该咋办」，逐行对号入座，结论落到 调整 / 观察 / 送医
4. **N 个自测** —— 在家就能做的验证动作，每条"怎么做 + 怎么读（两个结果分支）"

**为什么拆 A/B**：10 行挤一张时正文只能到 21px（手机约 6.6px，根本读不了）。拆 5+5 后正文可到 24–25px，同时把一期图数从 3 补到 4（平台建议 4–9 张，3 张偏单薄）。
**拆分线**＝「能不能在家处理」：A = 绿+黄（先在家试 / 先记录），B = 黄+红（别在家拖）。

### 二期 · 怎么办（6 图）—— 读者的念头是"那我现在到底该做啥？"

1. **谁更容易中招**（年龄 + 品种档卡，底部声明"概率提示，不是诊断线"）
2. **吐、咳、反流别搞混**（逐行对比，读者最容易踩的坑）
3. **一周吐几次算不正常**（分档 + 记账四样）
4. **先做这一件事**（喂法 3 条 + 时间线）
5. **你管它叫什么**（其他叫法 / 方言 / 网络说法，共鸣 + 吃搜索词）
6. **小技巧**（老手 9 条，全篇题眼，收尾"没有一条是买什么，全是怎么喂"式）

## 7. 发布文案（每期一份 .md）

- **标题 3 选 1**，全部 **≤20 字**，搜索词前置；**两期后半句必须各不同**（防平台判同质）
- **正文顺序**：还原那一秒的慌 → 一句话结论 → 图导览 → 该做什么 → 声明 + 出处 → 预告下一期
- **标签**：5 个左右，症状词 + 泛词 + 人群词
- 节奏：隔天发一期，别同天连发抢流量

### 7.1 真实经历怎么写（2026-10-10 用户要求）

用户原话：**「更多地注重场面的描述，要体现得像真实一样，还有我心里是怎么想的都要写出来。」**

正文开头那段"那一秒的慌"，**三要素缺一不可**：

| 要素 | 要求 | 反例 → 正例 |
|---|---|---|
| **① 场面** | 时间 + 地点 + 具体动作，用镜头语言，**不用概括** | ❌「它吐了，我很担心」<br>✅「半夜三点，那声"呕"从客厅传过来。我腾地就坐起来了，光脚踩过去，地板上已经一摊。」 |
| **② 心里的念头** | 写**当时真实的第一反应**，包括不理性的、自相矛盾的 | ✅「第一反应不是"这是什么病"，是"是不是我喂错了"」<br>✅「去了，怕大半夜小题大做；不去，又怕真耽误了什么。」 |
| **③ 一个具体动作细节** | 证明你真在场 | ✅「我还拿手机拍了照，想搜"猫吐了怎么办"」<br>✅「我把碗端到它跟前，它连头都没抬。」 |

**禁**：

- 禁写**疗效**（"后来换了粮就好了"）—— 红线 7
- 禁从"我"滑回"大家"（"大多数主人都会…"）—— 一滑就假
- 禁与上一期用**同一句式**。01 用了「最难受的不是X，是我不知道该不该带它去医院」，02 就必须换个说法
- **禁编造。写之前先问，不要先编。** 正文那段经历必须由用户口述，AI 只负责整理成文字。
  - ⚠️ **不要写草稿再让用户改** —— 草稿一出来，用户很容易“差不多就这样”，真实细节就被稀释了（2026-10-11 从 03 的教训改）

## 8. 去 AI 味规范（2026-10-10 新增，与红线同级）

> 依据：humanizer（Wikipedia「Signs of AI writing」）。定稿实测把破折号从 42 处清到 0。

1. **破折号 `——` 清零**。需要停顿用 `。` 或 `：`。唯一例外是人设落款里那个（换成 `。`，见 §1）
2. **去 AI 味 ≠ 去口语化。** 方向恰恰相反：是让文字**更像人说话**。口语词（"压根""饿不起""别扭""死角""改不掉"）**全部保留**，被清掉的只有机械句式
2. **顶标禁「你是不是…？」同款句式**。9 张里 7 张一个模子是最大的 AI 味。改**陈述句 + 具体场景**（"半夜那声"呕"，能让人从床上弹起来。"）
3. **图导览禁「图1：… 图2：… 图3：…」**。改「第一张… 第二张… 最后一张…」，或打散成不同动词（"第一张说…／第二张讲…／第三张给一条线…"）
4. **禁「不是 A，是 B」负向排比堆叠**（"没有一条是买什么，全是怎么喂"这种，一条里最多留一个）
5. **禁每条都用「X 个自测」「先分 N 档」这类完全同构的标题句式**
6. 中文引号 `“”` 是**正确排版**，不是 AI 味，不用改
7. 自检口径：把症状词抠掉换成别的症状，**读起来毫无违和 ＝ 同质化，重写**

## 9. 红线（写死，违者重写）

1. 症状 ≠ 诊断：所有"如果你家猫 X →"结尾落到"由兽医排查"，不给单一病因结论
2. 禁提检查项、不制造焦虑；紧迫话术只进警示区/红色叶子，不进标题、不进正文开头
3. 用药必须医院处方；禁提人药给猫
4. 每条独立成文，禁跨条引用；出处写全称；**每张图都要有出处**
5. "猫粮导致××"类归因不采信（2026 版犬猫运动功能障碍指南明确排除合规猫粮）
6. 禁英文术语；禁夸大承诺词（一站式/包治/彻底解决/根治）
7. **"我"要真实，但不卖疗效。**（2026-10-10 用户修订：他家猫确实吐过，情绪是真的）
   - ✅ **允许**：讲当时的**状态、困惑、踩的坑、情绪** —— "半夜听见那声呕，我腾地就坐起来了""我第一反应是喂错了，先把它抱起来看"
   - ❌ **仍然禁止**：讲**疗效** —— "我换了粮它就好了""照我说的做一定能好"。单猫局限，一个人不能替所有人下结论
   - 信任仍然靠**方法论透明**（翻了什么、出处哪条全交代），不靠"我试过所以你对"
8. **标题 ≤20 字**（超了发不出去）

## 10. 同质化防御（2026-10-09 新增，与红线同级）

**判定机制**：平台判的是「**句式 / 结构 / 高频词组合**」，**不是主题是否相同**。不同症状用同一套模板**不违规**；违规的是**"套用模板来做号"**—— 小红书 2026-04《AI 内容治理规则》明文反对「借助 AI 大批量制作同质化内容」「套用模板来做号」。
（口径：平台治理规则原文 + 第三方检测工具实测；**官方不公开相似度算法与阈值**，下述数字非官方值。）

**分层处理**：

| 层 | 处理 |
|---|---|
| 版式、配色、字号 | ✅ **照旧复用** —— 但要满足下方「3 条线」 |
| 症状、现象、人群、文献 | ✅ **天然不同**（72 条大表逐条取材，这是我们的优势）|
| **开头第一句、顶标、主标、副标、图导览句式、标题句式、收尾句** | ⚠️ **每条必须重写，禁同一句式** |
| 列头（具体症状／可能是什么原因／下一步怎么做）、结论词（可在家调理／记两周看趋势／当天去医院）、免责声明、人设落款、序号 | ✅ **原样保留**（版式固定件 + 合规件）|

### 版式统一 ≠ 同质化（2026-10-10 联网核实，v2.0.0 修订）

**平台明确鼓励「封面风格统一」** —— 用户一眼能认出"这是哪个博主的笔记"，建立辨识度。
被判的是**同一张封面图换标题反复用**，或**内容结构 + 文案都差不多**。

**官方口径**（小红书 AI 内容治理规则，2026-04-27 公告原文）：
> **AI低质**：**套用模板批量生产同质化内容**、以猎奇画面博眼球，或传播极端不良价值观。
> 处置：根据情节轻重，采取**限制分发、封禁账号**等梯度处置措施。

**第三方拆解的关键澄清**：
- ✅ **风格统一** ＝ 每篇封面整体风格一致（都是"大字+背景"）→ **平台鼓励**
- ❌ **同质化** ＝ 同一张图只做剪裁／调色／加水印／翻转，换标题反复用
- 判定看两件事：**① 内容有没有新增量？② 有没有你个人的风格？**
- **图文比视频判得严** —— 因为**图文会被 OCR 抓取，文案相似度一目了然**

### 本栏目实测基线（01 吐了 vs 02 不吃东西，2026-10-10）

| 指标 | 实测 | 判断 |
|---|---|---|
| CSS 版式重合 | 平均 **62.6%**（四列全链 A/B 最高 91.3%） | ✅ 可接受 |
| 图上文字重合 | **18.3%**（02 共 290 行，53 行与 01 相同） | ✅ 可接受 |
| 那 53 行是什么 | 列头 / 结论词 / 免责声明 / 人设落款 / 序号 | ✅ 全是版式固定件与合规件 |
| **真实内容重合**（症状 / 原因 / 动作） | **0** | ✅ 这才是平台真正看的 |

> 复测方法：抽 `<style>` 里的 CSS 规则做集合比对；抽可见文字逐行比对。

### 守不住就会出事的 3 条线

1. **图上文字是重灾区。** 图文会被 OCR 抓，图上文案同样进文本比对 → **顶标 / 主标 / 副标 / 标题每条必须重写**，禁同一句式。
2. **「批量」是红线。** 官方禁的是「套用模板**批量**生产」。见下方 §版式锁定与变化位。
3. **内容增量必须是真的。** 症状 / 原因 / 动作 100% 从底表逐条取材，不能套话填空。

### 版式锁定（硬规则，2.5.2 校准）

**默认动作：11 张图全部照抄母版骨架，只换文字。这不是偷懒，是标准做法。**

- 母版 = 最新一期定稿目录（当前 `成果物/03-软便/定稿/`）
- 画布 1242×1656（3:4）、三色语义与色值、字号阶梯、图序与图数（一期 5 图 / 二期 6 图）、列头与结论词、人设落款、免责声明 —— **一个字不改**
- **好处很实在**：省时、少出错、系列辨识度高，而且**平台明确鼓励"风格统一"**

#### 平台到底管什么（2026-10 联网核实）

| 平台管的 | 平台不管的 |
|---|---|
| 「套用模板**批量**生产**同质化内容**」—— 管的是**内容** | 排版长得一样 |
| 内容有没有**新增量** | 配色、字号、列数一致 |
| 有没有**你个人的风格** | 图序、图数固定 |

**「封面风格统一」被平台明确鼓励** —— 用户一眼认出是你的号，建立辨识度。

→ **所以：排版可以完全一样，内容必须每期不同。** 顶标 / 主标 / 副标 / 标题 / 封面大字 / 正文 / 图上文字，**这些才是要下功夫的地方**，不是版式。

#### 唯一例外（不强制，看情况才动）

只有当**内容硬套四列全链会明显变差**时，才换一期主图的形态，**并且必须在文案开头写清理由**。

- 例：03 软便的核心是"便便长什么样"，读者是拿着手机对着猫砂盆认的 → 换成「便便形态卡」确实更快对上号
- **但照抄四列全链也完全可以交付。** 别为了换而换 —— 换形态的代价是重新设计一遍版式，能省则省。

#### 可选彩蛋（同样不强制）

二期图5 可以在 A / B / C 三个形式里换一个，成本很低：

| 候选 | 形式 |
|---|---|
| **A · 词云块** | 分组胶囊标签（平时这么说 / 各地的老话 / 网上的说法） |
| **B · 主人原话气泡** | 一排对话气泡，写主人真实会说的话 |
| **C · 搜索框模拟** | 模拟小红书搜索框 + 下拉联想词 |

用了哪个就在文案开头写一行 `变化位②：B`。**这是锦上添花，不是必做动作。**

**图片会被怎么检测**：
- 图像指纹（感知哈希）只用于判**盗图 / 搬运**，比对像素 → 版式相同**不触发**
- **OCR 会读图上的字** → 图上文案同样进文本比对 → **图上文字也要防同构**

**AI 标注**（2026-10-10 联网核实，v2.4.0 修订）：

- **两层都要**：发布页勾选 AI 声明 + **可见标识**（图文标在标题下方或文末）。只做一层可能被判"未标注"。
- **主动标 vs 被动补标**：主动标 = 标识 + 正常分发；**不标被系统检测到 = 自动补标 + 限制分发**。所以"躲标"的成本比主动标更高。
- 官方口径：**标注本身不是降权理由**；真正限流的是同质化与"内容里没有人"。但第三方实测文章普遍反映"被打上标签就限流"——**保守按"会被限流"对待更稳**。
- ⚠️ **判定依据是"这段文字读起来的样子"，不是你勾没勾。** 所以把文字写实，比躲标有用得多。
- 官方区分：**AI 辅助创作（支持）** vs **AI 不当使用（打击）**。"**工具参与了流程 ≠ 内容是生成的**"——自己写的稿子让 AI 改错别字，不算生成；AI 写稿 + 自己配音属中间地带，稳妥该标。
- 误判存在（纯人工也可能被标）。申诉靠**过程留痕**：编辑历史、原始照片、灵感来源记录。
- **实操结论**：该标就标，同时把内容做实（§7.1 的真实经历）。这两件事各管各的，谁也替代不了谁。

**留人味**：每条至少留一处 AI 给不出来的 —— 真实经历 / 踩过的坑 / 个人判断。⚠️ 与红线 7 冲突时，人味走**"翻了什么、出处哪条全交代"的方法论透明**，不走"我家猫试了有效"。

**数字口径（第三方实测，非官方）**：原创性权重 ≥30%；重复率 >15% 影响收录；同质化评分 >35% 明显拖流量，<15% 正常。

**发布后自查**：发布 2h 内曝光比账号均值低约 20% → 大概率暗限流，回查同质化 / AI 味 / 敏感词 / 标题合规。
