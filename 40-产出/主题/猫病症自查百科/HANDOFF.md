## 工程备忘（Windows 本机）

- 图 = 自包含 HTML → chrome headless 截图：`"C:/Program Files/Google/Chrome/Application/chrome.exe" --headless=new --disable-gpu --no-sandbox --force-device-scale-factor=2 --window-size=1242,1242 --screenshot=TEMP路径.png file:///...`（输出禁中文路径，先 TEMP 再 cp；目标 PNG 被查看器占用报 busy 就换名）
- CSS 坑：颜色类与子元素类同名会串色（改名）；flex 容器混排 `<b>` 会拆字（改块级）；emoji 变方框（用 CSS 圆点）；SVG 色值写死禁 var()
- **布局坑（2026-10-10 踩过）**：元素用 `flex:1` 撑满整屏 → 行距被撑宽、显得空；用 `space-evenly` → 元素被拉开、显得散。**正确做法：元素按内容高度紧凑、整体居中**
- 截图后必须 Read 看图复核：溢出/孤字/undefined
- 无 Python 一律 Node；改长中文表整文件重写 + 回读校验
