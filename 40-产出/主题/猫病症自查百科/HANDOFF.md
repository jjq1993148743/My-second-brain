## 工程备忘（Windows 本机）

- 图 = 自包含 HTML → chrome headless 截图：
  `"C:/Program Files/Google/Chrome/Application/chrome.exe" --headless=new --disable-gpu --no-sandbox --force-device-scale-factor=2 --window-size=1242,1656 --screenshot=$TEMP/out.png "file:///C:/完整/Windows/路径.html"`（输出先落 TEMP 再 cp 回中文目录）
- ⚠️ `file:///` 后面必须是 **Windows 式路径**（`C:/...`）；写成 MSYS 式（`/c/...`）会变成 `file:////c/...` 报 `ERR_FILE_NOT_FOUND`
- ⚠️ **heredoc 里 Python 的 `\d` 会被吃掉**，正则静默失效 → 复杂脚本先用 Write 落成 `.py` 再跑
- CSS 坑：颜色类与子元素类同名会串色（改名）；flex 容器混排 `<b>` 会拆字（改块级）；emoji 变方框（用 CSS 圆点）；SVG 色值写死禁 `var()`
- **布局坑**：主内容区用 `flex:1` 撑满 → 行距被撑宽、显得空；用 `space-evenly` → 元素被拉开、显得散。**正确做法：元素按内容高度紧凑、整体居中**
- 截图后必须 Read 看图复核：溢出/孤字/undefined/NaN
- 无 Python 一律 Node；改长中文表整文件重写 + 回读校验
- push 到 GitHub：**本机直连可用，无需代理**（旧文档里"需代理 7897"那条已过时）
