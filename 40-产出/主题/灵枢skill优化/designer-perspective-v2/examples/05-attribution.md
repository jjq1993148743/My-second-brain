# Example · 归因与蒸馏（失败之后）

背景：上一轮判断「browser 类里 PDF 只出现 3 次 = 真空，应该做 PDF 插件」。

[归因]
任务真实条件：全生态 6,378 个插件里 PDF/OCR 相关有 151 个
模型感知条件：只搜了 browser 类（139 个）的描述
机制声明条件：搜索范围没有先做全局再下结论的纪律
→ 失败 = 三方失配（模型感知范围 < 任务真实范围）

[五失配维度]
观测位置：只看了单类，未站全局
观测工具：关键词匹配不等于需求覆盖
（其余三维未失配）

[蒸馏纪律（带适用条件）]
> **下「真空/空白」结论前，必须先用宽泛关键词做全局搜索；局部搜索结果只能用于排除，不能用于断言存在真空。**
> 适用条件：任何「这个方向没人做」类判断。

[注入]
写入记忆，下次遇到「真空判断」类任务时先全局验证。
