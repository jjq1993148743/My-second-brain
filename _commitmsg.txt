DSH插件曝光操作手册：实测发现打topic标签就自动收录不用逐个提交，三个插件已按收录要求补全元数据并测试通过

实测4个提交页做细到字段的曝光手册，发现重大简化。

最重要发现：dshmarketplace.dev原文说The faster route: tag your repository. Adding that topic to your repository gets you listed on the next sync, with no submission needed。打上dsh-plugin标签下次同步自动收录不需要提交表单。命令gh repo edit --add-topic dsh-plugin或手动GitHub仓库点About旁齿轮Topics填dsh-plugin。这意味着不用逐个提交7个站只需准备好仓库元数据。

三个自动收录的站：dshmarketplace.dev打topic自动同步、awesome-dsh-plugin.com从GitHub抓有RSS、dshopen.org从索引仓库抓可能需PR。

dsh-plugin.org的8条硬性要求（实测原文）：1仓库必须公开The repo must be public so this hub can scan it；2必须打dsh-plugin标签；3README必须有安装命令such as dsh plugin --profile web add package；4根目录必须有package.json with package name and version；5发到npm the Plugin Hub only lists plugins published to NPM；6有license MIT Apache-2.0；7准确分类11 categories；8说明权限Declare permissions external services and compatibility。

各站实测状态：dsh-plugin.org/submit有效200需按模板格式提交；dshmarketplace.dev/submit有效200粘贴仓库URL点Inspect；awesome-dsh-plugin/submit 404打标签自动收录；dshopen.org/submit 404提PR到polang233/dsh-plugin-index。

dsh-plugin.org给的固定提交格式模板：[Plugin submission] owner/repo — one-line value，### Repository 仓库地址，### What changes 装后有什么变化一句话，### Category 11分类之一。我们的填写示例：[Plugin submission] 用户名/dsh-sales-script — 销售话术库20+异议场景一键查，### What changes 装上后可以直接问DSH客户说太贵了怎么回它会给出带公式的完整话术不用再翻笔记，### Category Productivity。

重要提醒dsh-plugin.org强调Say exactly what changes不要写提升效率这种空话要写具体：销售插件装后客户说太贵了时直接给5步应对话术、HR插件30秒判断简历是否值得面试、律师插件合同审查7大类42项清单逐条打勾。

已按收录要求补全三个插件：package.json加了author为YOUR_NAME、files数组index.js cordis.patch.yml kb README.md setup.mjs、engines node大于等于18、category（销售和HR是Productivity/Business律师是Productivity/Legal）；README顶部加了分类、装上后有什么变化、权限声明（文件读取kb目录不联网不执行命令不访问凭据）、兼容性DSH大于等于0.2.0 Node大于等于18。补全后测试三个插件全部通过（销售174字符HR 693字符律师955字符）。

优化后的完整操作顺序约2小时比原来省一半时间：第1步准备30分钟（package.json补字段、README加分类权限兼容性、三个插件都改好已由我完成）；第2步建仓库打标签30分钟（建3个GitHub公开仓库、git push、gh repo edit --add-topic dsh-plugin三个都打）；第3步发npm 15分钟；第4步等自动收录1-7天（dshmarketplace下次同步自动收录、awesome抓取后进RSS）；第5步主动提交2个20分钟（dsh-plugin.org/submit按模板、dshmarketplace.dev/submit粘URL）；第6步提PR到dshopen 15分钟；第7步投稿日报20分钟。
